# 実装計画書: 第16号魔獣【白霧梟】（Frost-Mist Owl / *Strix cryophilus*）

---

## 1. 概要
合意された仕様書（`.specify/specs/016_shirakiri_owl.spec.md`）および新・高規格テンプレート（全9章構成）に基づき、第16号エントリー「白霧梟（シラキリフクロウ）」の図鑑記事、3大視覚アセット、Mermaid構造図、GURPS弾道・魔導データ、および各種管理ドキュメントの構築を実施する。

### Phase 2: 図鑑エントリー執筆（`creatures/016_shirakiri_owl.md` 全9章）
- [ ] **第1章: 基本分類・メタデータ**

- [ ] **第2章: 伝承考証とマナ覚醒の架橋**
  - 『古事記』『遠野物語』の夜啼鳥、アイヌ伝承コタンコロカムイ、奥多摩杣人の「白霧の神使」伝承と、2000年マナ覚醒（鍾乳洞冷気湧出帯）の科学的架橋。
- [ ] **第3章: 生物学的特徴・ライフステージ**
  - 全長 55〜70cm / 翼開長 125〜150cm / 体重 1.2〜2.4kg。吸熱ケラチン羽毛（DR 2 / 防音・防熱）、極低温冷却嚢（-30℃冷気生成）、三次元音響定位顔盤。
  - 幼鳥（綿毛・Threat Level I）→ 成鳥（Threat Level I〜II）→ **主級・古樹共生個体（Elder Alpha / 翼開長2m・Threat Level III / 《絶対零度結界》）**。
  - Mermaid生体解剖図（`flowchart TD / subgraph`）。
- [ ] **第4章: 生態・食物連鎖・相互作用**
  - 食性（トゲヘビ、野鼠、コウモリ）、トゲヘビ捕食フロー（冷気外套サーマル隠蔽→無音急降下→《瞬間凍結》ブレス→岩盤落下→腹板捕食）。
  - 旋風鎌鼬（014）との生息域住み分け、剛毛巌猪（001）との不干渉。Mermaid生態系図（`flowchart LR`）。
- [ ] **第5章: 魔導科学・背景ロア**
  - 《冷気》《瞬間凍結》《無音化》の生体励起。音響ログ（0dB無音滑空、5〜12Hz超低周波冷気渦、250〜400Hz凍結鳴き声）。
  - メガコーポ（ヤマト重工の潜水艦用吸音フェザー、三ツ菱マナテックの超伝導冷却研究）。
- [ ] **第6章: 交戦・防災・ミリタリータクティクス**
