# 実装計画書: 第17号魔獣【白霊千鳥（カラドリウス）】（Caladrius / *Charadrius caladrius*）

---

## 1. 概要
確定した仕様書（`.specify/specs/017_caladrius.spec.md`）および新・高規格テンプレート（全9章構成）に基づき、第17号エントリー「白霊千鳥（カラドリウス）」の図鑑記事、3大視覚アセット、Mermaid構造図、GURPS弾道・魔導データ、および各種管理ドキュメントの構築を実施する。

- [ ] **第2章: 伝承考証とマナ覚醒の架橋**

- [ ] **第3章: 生物学的特徴・ライフステージ**
  - 全長 18〜22cm / 翼開長 38〜44cm / 体重 45〜65g。完全純白ケラチン羽毛（DR 1 / マナフィルター）、胸骨奥の生体魔力浄化嚢（*Bursa Cathartica*）、複眼マナスキャン瞳孔。
  - 幼鳥（羽毛未成熟・Threat Level I）→ 成鳥（Threat Level I）→ **古代覚醒神使個体（Elder Ancient / 翼開長60cm・純白光輪・Threat Level II）**。
  - Mermaid生体解剖図（`flowchart TD / subgraph`）。
- [ ] **第4章: 生態・食物連鎖・相互作用**
  - 食性（清浄な水生甲殻類、霊水珪藻、微細藻類）、地中海での野生生態と日本における外来輸入・VIP病棟飼育動態。
  - 臨床運用フロー（医師診断→前処置薬投与→視線共鳴吸引→屋上サンルーム放鳥・太陽光昇華→白霊砂採取）。Mermaid臨床治癒図（`flowchart TD`）。
- [ ] **第5章: 魔導科学・背景ロア**
