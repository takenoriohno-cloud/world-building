# プロジェクト憲章 (Project Constitution)
<!-- .specify/memory/constitution.md -->

本ドキュメントは、「現代魔獣・幻獣生態図鑑プロジェクト」における最高法規（憲章）です。すべての仕様書（Spec）、計画（Plan）、タスク（Tasks）、実装（Implementation）は本憲章に厳格に従わなければならず、違反・矛盾・設定の未確認削除が発生した場合は直ちに処理を停止（HALT）し、ユーザーとの合意形成を行わなければなりません。

---

## 1. 世界観絶対不変原則（Core Principles）

1. **2000年マナ覚醒（ミレニアム・アウェイクニング）と26年時間軸**:
   - 西暦2000年1月1日にマナが覚醒。現代（2026年）は覚醒から**約26年**が経過した社会。
   - 生態系成立は「既存生物の急速変異」「古代種の覚醒」「異界・アビス特異点からの流入」のハイブリッドモデル。新人類（エルフ・ドワーフ・トロール等）も26年前より誕生。
2. **物理・科学と魔術の完全並行＆生体媒介原則**:
   - マナは電子機器や通信波、物理インフラとは非干渉。半導体・インターネットは正常稼働。
   - マナは「生体組織」「精神・神経系」「魂・アストラル体」にのみ作用する。
   - テクノマジック・電脳魔術は、術士が生体電位を介して端末に同調する「生体媒介技術」に限定され、一般量産化前の黎明期にある。
3. **軍事・兵器バランスと魔術障壁力学**:
   - 通常魔獣は小銃・重機関銃等の通常火器で駆除可能。
   - 魔術障壁を持つ魔獣も、12.7mm徹甲弾、重火器、ミサイル、爆風等の物理運動エネルギーで障壁ごと粉砕・突破可能。
   - 霊体・非実体ゴーストのみ現代通常火器が無効であり、専門魔法部隊（術士・陰陽師等）が出動。
   - 超越種（高知能竜種・神性存在）は軍隊であっても「絶対不可侵・天災指定」として関与を避ける。
4. **多層同心円要塞網と結界都市（東京モデル）**:
   - 第1同心円（皇居・山手線内側コア）、第2同心円（環七・外環防護壁）、第3同心円（国道16号・圏央道要塞線）、壁外（奥多摩・秩父魔境、東京湾アビス）。
5. **メガコーポ支配と新人類（メタヒューマン）社会構造**:
   - 世界BIG5および日本4大メガコーポ（ヤマト重工、テイコク製薬、三ツ菱マナテック、豊洲中央流通HD）が流通・軍事・製薬・食肉を掌握。
   - 新人類は「魔力適性者ID携帯義務」等の法的制限と差別を受け、湾岸スラム集住や危険な壁外ハンター職に従事。
6. **三段階資源・食肉分類法（Class-A / B / C）**:
   - 「魔力抜き」という科学的処理は存在しない。
   - Class-A（安全種: 一般流通・養殖可）、Class-B（要処理種: 免許制ジビエ・毒腺や呪術下処理必須）、Class-C（汚染種: 食用厳禁・バイオハザード劇物）。

## 2. 仕様書駆動（SDD）品質ゲート原則

- **仕様書の先行義務**: いかなる魔獣記事、世界観設定、ルール拡張も、まず `.specify/specs/` 配下に仕様書（Spec）を作成し、レビュー・合意を経てから実装すること。
- **不一致時の即時停止（HALT）**: 既存仕様や憲章と1点でも不整合がある場合、AIは推測で進めず停止し、選択肢を提示してすり合わせを行うこと。
- **ツール失敗・クォータ枯渇時の即時ブロック**: 画像生成（`generate_image`）や外部調査ツール等の実行時にクォータ枯渇（HTTP 429等）やエラーが発生した場合、最後まで成果物を作成して完了扱いとせず、直ちにブロック（HALT）してユーザーに報告・指示を仰ぐこと。
- **エビデンス永続化**: すべてのすり合わせ結果と合意理由は `doc/questions_and_answers.md` および `doc/audit.log` に記録し、正史エビデンスとして保持すること。
