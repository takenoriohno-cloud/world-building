- **ユーザー要件**: 「鋼」や「鎧」のような装甲・力押しに依存しない、独創的かつ生物学的・知性的・魔導科学的ギミックによるトゲヘビの天敵の策定。
- **適用規格**: `TEMPLATE.md` 新・高規格全9章構成、および `AGENTS.md` 最上位憲章。

## 3. 5専門部署＆憲章監査室 事前審査見解（Gate 1 審査）

1. **🐾 生態・生物調査部**:
   - 物理装甲の打ち合いではなく、「変温動物の急冷麻痺」「道具を使った知性捕食」「固有振動数による共鳴破壊」は、現実の生物学（フクロウの無音飛行・カラスの道具使用・コウモリの超音波）に深く根ざした極めて説得力のある設計。
2. **🌍 地理・環境調査部**:
   - 奥多摩・丹沢・秩父アウトランドのカルスト山林・鍾乳洞窟網に自然に生息可能。
3. **🏛️ 歴史・社会制度考証部**:
   - 2000年マナ覚醒から26年で、トゲヘビのチタン棘や毒の脅威を「知恵」や「特殊能力」で克服した新世代魔獣として位置づけ。
4. **⚡ 魔導科学・理論研究部**:
   - 《冷気》《超音波共鳴》《道具操作》等、生体媒介原則（術士・生体マナ共鳴）に完全適合。
5. **📸 視覚・音響資料部**:
   - それぞれ極めて特徴的なビジュアル（冷気霧を纏う純白フクロウ、石を抱えて投下する黒烏、超音波を放つ怪異コウモリ）と音響ログが設計可能。
6. **⚖️ 憲章監査室**:
   - 憲章5大観点および015（被食）との食物連鎖クロスリレーションに完全適合。

## 4. 非装甲・新アプローチ 3大候補案

### 案A: 【氷霧無音梟】（ヒョウムムオンキョウ / *Strix cryophilus* / Frost-Mist Owl / 凍霧フクロウ）★推奨
- **モチーフ**: フクロウ（完全無音飛行・冷気魔導・急冷麻痺）
- **分類**: 脊索動物門 鳥綱 フクロウ目 フクロウ科 / Class-A（安全種） / Threat Level: II
- **捕食機序**:
  - **サーマル完全隠蔽（冷気外套）**: 自身の周囲に微細な冷気霧を纏い、ピット器官の赤外線・熱源探知に一切映らない状態で完全無音飛行。
  - **急冷凍結ブレス（《瞬間凍結》）**: トゲヘビの上空から氷点下の冷気を浴びせ、変温動物であるトゲヘビの筋膜を瞬間凍結させて棘射出を封殺（フリーズ）。動けなくなったトゲヘビを岩盤へ叩きつけ、腹板をつついて捕食。

### 案B: 【智慧道具鴉】（チエドウグガラス / *Corvus callidus* / Tool-using Clever Raven / 道具使烏）
- **モチーフ**: カラス（高度な知性・道具使用・高空投石・集団連携）
- **分類**: 脊索動物門 鳥綱 スズメ目 カラス科 / Class-A（安全種） / Threat Level: II
- **捕食機序**:
  - **15m射程の完全把握**: トゲヘビの棘射出が届かない樹上や20m上空を旋回。
  - **精密投石爆撃＆裏返し**: 重い尖った石（チャート石）を高空からトゲヘビの頭部に正確に投下して昏倒させ、木の枝を使ってトゲヘビを器用に仰向けに裏返し、トゲのない白い腹板（DR 3）から内臓を巧みに引き抜いて捕食。

### 案C: 【破砕共鳴蝙蝠】（ハサイキョウメイコウモリ / *Rhinolophus sonocrastus* / Resonance-Crusher Bat / 共鳴コウモリ）
- **モチーフ**: コウモリ（音響共鳴・周波数自壊・超音波）
- **分類**: 脊索動物門 哺乳綱 翼手目 キクガシラコウモリ科 / Class-B（要処理種） / Threat Level: II
- **捕食機序**:
  - **ストリデュレーション逆位相照射**: トゲヘビが放つ威嚇音（35〜52kHz）を受信し、棘の固有振動数に同期させた「高出力共鳴超音波（120dB+）」を放射。
  - **共鳴自壊（レゾナンス・ストリップ）**: トゲヘビの全身の棘を根元から共振させて脱落・粉砕し、丸裸（DR 2）にしたところへ急降下して捕食。
