## 1. 概要と目的 (Overview & Goal)
- **対象**: アメリカのメガプレックス（都市圏スラム・路地裏）において、ストリートシャーマンが都市環境のマナと廃棄物を媒介にして召喚・具現化する都市精霊（Urban Spirit）。
- **目的・背景**: 
  - 『AGENTS.md』および『world/magic_theory.md』第2.2項（伝統・儀式学派 / シャーマニズム）に基づき、自然信仰が近代巨大都市（コンクリート、アスファルト、排気ガス煤煙、ネオン管、廃金属）に適応・進化した「ストリートシャーマニズム」の使役霊体を公式図鑑化する。
  - 非物理存在（霊体）が都市の無機廃棄物を取り込んで物理シェルを構成する「ハイブリッド具現力学」および現代兵器・対霊戦術の科学的・魔導的リアリズムを確立する。

---

## 2. 憲章・絶対法則との整合性チェック (Constitution Alignment)
- [x] **2000年マナ覚醒（26年経過）**: 2000年以降、都市の集合無意識や環境マナと同調した新世代シャーマン（メタヒューマンや路地裏チルドレン）によって開拓された新体系。
- [x] **科学と魔法の完全並行・生体媒介原則**: 精霊自体はアストラル霊体であり電子回路に直接干渉しない。シャーマンの生体神経・トランス（ドラミング・呼吸法・アストラル同調）を媒介して現世に召喚される。
- [x] **通常火器・重火器・専門魔法部隊のバランス**: 
  - 霊体状態（Insubstantial）: 通常弾薬（5.56mm等）完全無効。
  - 具現化状態（Materialized）: アスファルト・コンクリート外殻（DR 6〜8）により小口径弾を跳弾・減衰。
  - 対処法: 12.7mm徹甲弾やスラッグ弾の圧倒的運動エネルギー（2,000J〜15,000J）で物理殻ごと核を衝撃粉砕可能。また警察・メガコーポPMCの「対霊退魔部隊（霊撃・呪符・ディスペル）」が特効。
- [x] **三段階資源分類**: **汚染・霊体種（Class-C / 非可食）**。肉体は存在せず消滅するが、凝縮マナ残滓（アーバン・エーテル・スラグ）や帯電ネオンガラス片がブラックマーケットで魔導触媒・電脳魔術用デバイス素材として高額取引される。
- [x] **メガコーポ・新人類社会構造**: シアトル・メトロプレックスやニューヨーク・ブロンクス等のスラム街で、メガコーポ（アレス社の治安部隊 Knight Errant 等）による再開発や立ち退きに対する自衛・ゲリラ戦の守護精霊として運用される。

## 3. 現実科学グラウンディング（外部リサーチ裏付け）
- **都市環境工学・材料科学**:
  - アスファルトコンクリート（ビチューメン＋骨材）：圧縮強度 15〜30 MPa、衝撃吸収性に優れる。
  - ネオン放電管（高電圧希ガス発光・プラズマ）：水銀蒸気・ネオンガスの励起発光。
  - 微小粒子状物質（PM2.5 / ディーゼル煤煙）：凝縮した炭素微粒子がアストラル核のフォグ（煙霧）を形成。
- **弾道学・交戦力学（GURPS 4e準拠）**:
  - 外殻（DR 6〜8）：9mm Parabellum（1d+1 pi）や 5.56mm NATO（5d pi）を大幅減衰。
  - 12.7×99mm NATO（13d+1 pi+ / 運動エネルギー約17,000J）：DRを貫通し、アストラル核を物理衝撃波で粉砕。
- **シャーマニズム文化・民俗学**:
  - 都市アニミズム（Urban Animism / Spectral Geography）：都市の構造物や廃棄物に「場所の霊（ゲニウス・ロキ）」が宿るという現代フォークロアの導入。

### ガープス第4版準拠ステータス（具現化時）
- **ST 18** (突進・打撃 1d+2 / 3d), **DX 11**, **IQ 8** (術士の命令遵守・街路本能), **HT 12**
- **HP 22**, **FP 12**, **BS 5.75**, **BM 6** (時速 21.6 km/h)
- **サイズ修正 (SM)**: **SM 0〜+1** (体高 1.8m〜2.2m, 構成素材質量 300〜500kg)
- **防護点 (DR)**: **DR 7** (アスファルト・コンクリート複合外殻)
- **特殊能力**:
  - *【半実体・霊体核（Astral Core）】*: 物理攻撃の貫通・切断致傷力は外殻破壊まで本体に通らない。
  - *【スモッグ・スクリーン（排気ガス噴射）】*: 周囲3mに視界阻害・催涙効果のある濃厚なPM2.5煤煙を展開（赤外線・暗視ペナルティ -4）。
  - *【アスファルト結合・同調（Asphalt Meld）】*: 道路舗装やコンクリート壁面に同化・潜伏し、奇襲時に急激に実体化。
