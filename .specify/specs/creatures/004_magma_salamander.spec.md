## 1. 概要と目的 (Overview & Goal)
- **対象**: 日本および世界の火山地帯（浅間山、草津白根、富士山溶岩洞、阿蘇カルデラ等）のマグマ湖・高温熱水脈に生息する超高温適応両生類魔獣「溶岩火椒魚（マグマ・サラマンダー / *Andrias vulcanus*）」。
- **目的・背景**: 
  - 本来清冷な渓流に生息するオオサンショウウオ（*Andrias japonicus*）が、2000年のマナ覚醒により火霊系高濃度マナとマグマ溜まりに適応・超変異したメカニズムを確立する。
  - 玄武岩・黒曜石質の超高耐熱セラミック外殻（DR 12）、体内生体燃焼炉（パイロ・オルガン）によるマグマ・硫黄ブレス噴射、および熱力学・消火冷却兵器との戦闘力学を詳細化する。

## 2. 憲章・絶対法則との整合性チェック (Constitution Alignment)
- [x] **2000年マナ覚醒（26年経過）**: 浅間山・富士山水系の地下熱水脈に生息していた個体群が、マナ噴出に伴う好熱性共生細菌・火霊マナにより約15世代で急速変異・大型化。
- [x] **科学と魔法の完全並行・生体媒介原則**: 体内での超高温維持・ブレス噴射は、生体組織（パイロ・オルガン）での火霊系マナ不随意行使《熱耐性》《火球》によるものであり、電磁気・通信機器には干渉しない（周囲への超高熱放射による物理的熱歪みのみ）。
- [x] **通常火器・重火器・消火部隊のバランス**:
  - 小口径弾（5.56mm/7.62mm）: 厚い黒曜石質外殻（DR 12）および体表面温度（約600〜900℃）により弾頭が溶解・跳弾。
  - 重火器（12.7mm M2徹甲弾 / 17,000J）: 外殻を貫通しダメージ。
  - 冷却・熱衝撃戦術（Cryo/Thermal Shock）: 液体窒素弾や高圧放水砲による急冷で外殻がヒートショック割れ（DR半減）、行動速度激減。
- [x] **三段階資源分類**: **要処理種（Class-B）**。可燃性硫黄を蓄積する「パイロ熱嚢」および重金属濃縮器官を専門解体師が完全除去すれば、高タンパクで滋養強壮に優れた極上肉（火椒肉）として高級ジビエ市場へ流通。
- [x] **メガコーポ・社会構造**: ヤマト重工・テイコク製薬が耐熱外皮（耐熱複合装甲材）および生体耐熱酵素の原料としてハンターに高額懸賞金を提示。

## 3. 現実科学グラウンディング（外部リサーチ裏付け）
- **原種解剖学**: オオサンショウウオ（扁平頭部、強力な吸引捕食、皮膚呼吸、軟骨性骨格）。変異種では皮膚呼吸が珪酸塩微細多孔質プレートによる「超臨界流体ガス交換」へと進化。
- **火山岩・鉱物学**: 玄武岩（融点 1,000〜1,200℃）、黒曜石（珪酸塩ガラス質）、硫黄華（融点 115℃ / 沸点 444℃）。
- **弾道・熱力学（GURPS 4e準拠）**:
  - 外殻（DR 12 / 耐火災・耐熱DR 30）: 5.56mm NATO（5d pi, 平均17.5）の貫通を阻止。
  - 12.7mm徹甲弾（13d+1(2) pi+ / 平均46.5）で装甲貫通・生体核破壊。
