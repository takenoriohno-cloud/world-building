## 1. 原種生物科学グラウンディング（外部リサーチ）
- **原種**: アマゾン熱帯雨林に生息するモルフォチョウ属（*Morpho*）およびドクチョウ属（*Heliconius*）。
- **光学メカニズム**: 微細な棚状ラメラ構造（構造色）による光の多重干渉。フラッシュ効果による捕食者撹乱。
- **生化学メカニズム**: トケイソウ（*Passiflora*）由来のシアン配糖体蓄積・生合成による化学防御。
- **生息地**: アマゾン川流域の原生熱帯雨林林冠層（キャノピー）〜林床部。

## 2. 魔獣仕様ドラフト（基本案）

| 項目 | 設定案 |
| :--- | :--- |
| **和名 / 学名** | 幻光モルフォ（ゲンコウモルフォ） / *Morpho phantasma* |
| **生息地** | アマゾン川上流セルバ原生林、特異災害指定地域「アマゾン・グリーン・ヘル」林冠層 |
| **分類・脅威度** | **Class-B（要処理種）** / **Threat Level II（局所危険）**（単体TL I、群生時TL III） |
| **変異起源** | **急速マナ変異種**（2000年のマナ覚醒により、構造色ナノ構造がマナ光屈折器官へ極限発達） |
| **魔導・生態特性** | 1. **光屈折・光学迷彩（カモフラージュ）**: 翅の微細マナ結晶が周囲の光を偏光させ、完全不可視化および残像（ミラージュ）を投影。<br>2. **幻惑・麻痺性燐粉（サイケデリック・ダスト）**: 鱗粉を吸入または皮膚付着すると強い幻覚、知覚麻痺、陶酔状態を引き起こす。<br>3. **集団共鳴（スウォーム・フラッシュ）**: 数十〜数百匹が一斉に翅を開閉することで強烈な目くらまし閃光（ストロボ・パルス）を放ち、敵の視神経を一時的に焼き切る。 |
| **軍事・討伐対策** | 単体は小型で脆弱（HP 2〜3、DR 0）。散弾銃（バードショット）や火炎放射器、風霊系呪文で容易に駆逐可能。ただし光学迷彩によりサーマル/赤外線ゴーグルおよびマナ探知機が必須。 |
| **食・素材利用** | **Class-B（要処理種）**: 翅の鱗粉は猛毒のため完全除去必須。胴体・蛹は高タンパクなジビエ・昆虫食として現地先住民族および探索隊に利用される。翅の結晶鱗粉は「光学迷彩繊維」「幻覚系霊薬（サイケデリック・エリクサー）」の原料として高額取引される。 |

## 3. 5専門部署＆憲章監査室の審査所見（Quality Gate）

1. **🐾 ① 生態・生物調査部**:
   - *所見*: モルフォチョウの構造色とドクチョウのシアン毒のハイブリッド変異として生物学的に極めて妥当。単体での脅威度（TL I）と群れ（Swarm / TL III）での脅威度を明確に分けることで、GURPSルール（`vehicles_and_swarms.md`）と自然に連動可能。
2. **🌍 ② 地理・環境調査部**:
   - *所見*: アマゾン奥地の「アマゾン・グリーン・ヘル」は南米最大のマナ高濃度熱帯林。キャノピー（地上30m以上の樹冠）に生息するため、空挺・ヘリ部隊やツリートップ探索班の視界遮断トラップとして地理的整合性が高い。
3. **🏛️ ③ 歴史・社会制度考証部**:
   - *所見*: アマゾンで活動するメガコーポ（アズテクノロジー社やテイコク製薬の南米支社）が、光学迷彩素材および精神薬理素材としての独占採取権を巡って現地PMCと衝突している裏設定を付与可能。
4. **⚡ ④ 魔導科学・理論研究部**:
   - *所見*: 生体媒介原則に準拠。電子回路を直接壊すのではなく、光の波長偏光（《幻影》《光》系統）と神経毒（精神操作・毒）に限定されているため、最上位憲章と完全合致。
5. **📸 ⑤ 視覚・音響・資料記録部**:
   - *所見*: 構造色のエメラルド〜シアンブルーの燐光、熱帯雨林の暗闇に浮かぶ残像の対比が映像・標本プロンプトとして非常に映える。音響は翅の羽ばたきによる超音波パルス（22kHz〜35kHz）を設計可能。
6. **⚖️ 【憲章監査室】**:
   - *所見*: `AGENTS.md` の絶対法則（26年時間軸・生体作用・Class-Bジビエ・軍事バランス）をすべて満たしており、憲章適合性に問題なし。
