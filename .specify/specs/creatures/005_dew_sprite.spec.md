## 1. 概要と目的 (Overview & Goal)
- **対象**: 2000年のマナ覚醒時に「精霊界（フェイ・プレーン / アストラル界）」から物質界へ流入し、ヨーロッパの原生林（シュヴァルツヴァルト黒い森、ブロセリアンドの森等）にそのまま定着・共生した微小精霊「朝露小精霊（デュー・スプライト / *Spiritus roris*）」。
- **目的・背景**:
  - 『AGENTS.md』第1.1項に定める生態系成立因のうち「異界・精霊界からの流入種」の実例として、非攻撃的・共生型の自然小精霊の生態と魔導力学を確立する。
  - 自然界の物理的物質（植物の蒸散水分、朝露）と精霊界マナを取り込んで物質界に存在を維持する「物質・マナ共生代謝」を詳細化する。

---

## 2. 憲章・絶対法則との整合性チェック (Constitution Alignment)
- [x] **2000年マナ覚醒（26年定着）**: 2000年の空間境界希薄化により精霊界から流入。森林の豊かな植物マナと朝露によって物質界に適応し、26年間生態系の一部として定着。
- [x] **科学と魔法の完全並行・生体媒介原則**: 電子機器とは非干渉。森の植物や小動物の生体組織・アストラル場と同調し、植物の治癒・成長を促す。
- [x] **戦闘・軍事バランス**:
  - **Threat Level: I（無害・警戒外 / 環境守護小精霊）**。
  - 戦闘力はほぼ皆無。脅威を察知すると水滴化・霧散して逃走。
  - 物理弾（小銃弾等）は液体・霊体のため貫通・無効（水滴が弾け飛ぶだけ）。
  - 熱・乾燥・火炎放射には脆弱だが、環境保護対象として軍事攻撃の対象外。
- [x] **三段階資源分類**: **安全種（Class-A / 非破壊的採取資源）**。精霊本体の殺傷・捕獲は欧州自然保護条約で禁止。彼らが分泌・凝縮する「朝露の雫（デュー・エリクサー）」は無毒で優れた疲労回復・治癒効果を持ち、高額な医薬品・化粧品原料となる。
- [x] **社会構造**: 欧州ドルイド保護区、サエデル・シュティフトゥング管理外縁区において、森の環境指標生物（インジケーター・スピリット）として丁重に保護。

## 3. 現実科学グラウンディング（外部リサーチ裏付け）
- **森林微気候・結露物理学**:
  - 放射冷却による露点到達、植物の蒸散作用（Transpiration）、表面張力による球状水滴形成。
  - マイナスイオンおよび植物性フィトンチッドの凝縮。
- **民俗学・ケルト/ゲルマン伝承**:
  - ヨーロッパの朝露信仰（May Dew）、ブロセリアンドの泉の精霊、シュヴァルツヴァルトの木精伝承。
- **GURPS 4thスケール力学**:
  - サイズ修正 **SM -5** (体長 10〜15cm / 浮遊水滴時 直径 3〜5cm、質量 30〜80g)。
  - ST 1, DX 14, IQ 6, HT 12, HP 3, FP 12, 飛行 BM 8。

### ガープス第4版準拠ステータス
- **ST 1** (物理攻撃力なし), **DX 14**, **IQ 6** (好奇心・無邪気・自然共生), **HT 12**
- **HP 3**, **FP 12**, **BS 6.5**, **BM 1** (地上) / **飛行 BM 8** (時速 28.8 km/h, 機動性優良)
- **サイズ修正 (SM)**: **SM -5** (体長 10〜15cm / 球状水滴時 直径 4cm, 体重 50g)
- **防護点 (DR)**: **DR 0** (流体・半実体: 貫通武器ダメージ半減)
- **生体励起呪文・特殊能力**:
  - *【水滴化・霧散（Liquid Dispersal）】*: 物理的衝撃を受けると瞬時に微小な水滴となって四散し、近隣の葉上で再凝縮する。
  - *【生体治癒露（Healing Dewdrop）】*: 毎朝分泌する露の玉は、水霊系《小治癒》《清浄化》の効果を持ち、負傷した小動物や植物を癒す。
  - *【淡光屈折（Phosphorescent Glow）】*: 夜明け前に淡い青緑色の燐光を放ち、周囲の植物の光合成マナを活性化。
