## 2. 外部科学・魔導理論グラウンディング

### 2.1 比較解剖学・生体構造データ
- **体躯スケール**: 体長 2.0〜2.6m / 体高 1.2〜1.5m / 体重 280〜450kg（SM +1 / 原種の約2.5倍）
- **直感的サイズ比較**: 成人男性（180cm）が横たわった全長を超え、軽自動車（車重約800kg）の半分に匹敵する突進質量。
- **骨格・装甲強度（DR値）**:
  - 鼻骨・頭頂骨のクラニアル・シールド: 厚さ 60〜90mm、骨密度強化（DR 6）。
  - 背部生体シリカ剛毛ニードルアーマー: ケイ素沈着繊維（DR 4 / 近接攻撃者へ 1d-1 刺し反射ダメージ）。
  - 胴体筋膜・厚皮: DR 3。
- **咬合力・牙攻撃力**:
  - 咬合力: **1,200 PSI（約8.3 MPa）**。
  - 下顎湾曲牙: 長さ 35〜48cm（Striker: 2d+1 切り・刺し）。
- **突進力学**:
  - 突進最高速度: 時速 54km（15 m/s / Move 15）。
  - 衝突運動エネルギー: 約 **39.4 kJ**（2トントラックの低速衝突、防護壁や一般車両を粉砕・横転させる衝撃）。

### 2.2 魔導生化学・生体媒介原則（GURPS突合）
- **励起生体異能・呪文**:
  - 《大地の盾》（Shield / `world/magic/spells/earth.md:38`）
  - 《硬質化/石の皮膚》（Stone Skin / `world/magic/spells/earth.md:45`）
- **生体媒介原則**: 電子機器には干渉せず、項部神経節が突進時の衝突Gを生体電位で感知し、不随意に筋組織とシリカ結晶を瞬間硬化。

### 2.3 地理・社会・軍事・食文化
- **一次野生生息地**: 日本・関東山地（奥多摩・秩父山岳魔境区、丹沢外縁、旧五日市街道廃墟群）。
- **軍事対処**: 5.56mm小銃弾はクラニアルシールドおよび背部シリカ剛毛で弾かれるか威力が激減。12.7mm M2重機関銃徹甲弾（約18,000J）または84mm無反動砲（カールグスタフ）の直撃による頭蓋・運動中枢粉砕が標準迎撃手順。
- **食文化・ジビエ**:
  - 伝統名物料理『八王子名物・巌猪の赤味噌ぼたん鍋』。
  - マナ受容節摘出後の肉は、石英鉱物代謝による高鉄分と引き締まった赤身が特徴。
