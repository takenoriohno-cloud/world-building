# 【確定仕様書】018: 影魚（カゲウオ / カゲエイ）

- **標準和名**: 影魚（カゲウオ / カゲエイ）
- **英語名**: Shadow-skate / Wall-swimming Shadowfish
- **学名**: *Umbrabatis plana*（エイ目カゲエイ科）
- **分類階級**: 脊索動物門 (Chordata) / 軟骨魚綱 (Chondrichthyes) / トビエイ目 (Myliobatiformes) / カゲエイ科 (Umbrabatidae) / カゲウオ属 (*Umbrabatis*) / 影魚種 (*U. plana*)
- **危険度ランク**: Threat Level I〜II（要注意種 / 局所集団時）
- **資源・ジビエ区分**: Class-B（要処理種 / 閃光実体化・皮剥ぎ湯引き可食）

## 第0章: 原典・神話伝承考証 ＆ 原典発祥地マッピング

### 1. 古典文献・神話伝承考証（シュルツ調査員）
1. **日本古代・中世海魔伝承「影鰐（カゲワニ）」**:
   - **原典文献**: 『出雲国風土記』『伯耆国風土記逸文』『太平記』『奇異雑談集』。
   - **具体的描写**: 海上や水面に映る人間や船の影を水底から呑み込む怪魚。影を呑まれた人間は直後に昏倒し、高熱を発して衰弱死する。鏡を海中に投げ入れると怪異が鏡に映る自身の影を呑んで砕け散るという退散譚が存在する。
   - **魔導生化学的架橋**: 影を食らう現象は、生物が投射する「マナ・アストラル結合境界（生体影）」を捕食することで、宿主の神経伝達電位および生体マナを吸出・衰弱させる現象として完全合致。
2. **2次元幾何学寓意・多次元投影論**:
   - **古典原典**: エドウィン・アボット・アボット『フラットランド（Flatland: A Romance of Many Dimensions）』（1884年）。
   - **具体的概念**: 3次元空間の立体が2次元平面を通過する際、平面の住民には「厚みのない切断面（影）」として知覚される。
   - **魔導物理学的架橋**: アビス特異点から漏れ出た異次元極薄マナ膜が、光と影の境界面（照度勾配の強いコンクリート壁面や路面）に吸着し、2次元投影体として質量を圧縮・保持したまま遊泳する「境界性軟骨魚類」として成立。

### 2. 原典発祥地マッピング（陣内調査官）
- **一次野生生息地（Primary Habitat）**:
  - **日本海沿岸（山陰・出雲・隠岐・若狭湾）の海食洞・暗黒岩礁帯**: 2000年マナ覚醒以前から潮だまりの暗がりに休眠していた古代軟骨魚類がアビス変異。
- **二次生息域・都市適応（Urban Expansion）**:
  - **結界都市・東京地下インフラ（第2・第3同心円）**:
    - 都営大江戸線・東京メトロ丸ノ内線の深部トンネル壁面、環七地下調節池、首都高速高架下の常時日陰エリア、廃ビルの地下ピット等。
    - 街灯やナトリウムランプの投光が作る「恒久的な人工影」を伝って群れで移動・遊泳。

## 第1章: 生物学的特徴・解剖学的構造
- **体躯・形態**:
  - 影遊泳時: 厚さ数マイクロメートル（実質2次元）。外見は漆黒のトビエイ・ヒラメに似たシルエットで、縁に青白い微弱なリン光を放つ。
  - 実体化時（強光照射後）: 体長30〜60cm、厚さ1〜2mmの極薄シート状軟骨魚類。半透明の黒褐色で、皮膚は微細な光子吸収ケラチン鱗で覆われる。
- **生体力学・推進原理**:
  - 壁面や路面の微小な凹凸とマナ静電気力（ファンデルワールス力様マナ吸着）を利用し、波状運動で時速20〜30km/hで壁面・天井を滑走する。

---

## 第2章: 生態・捕食・防衛行動
- **捕食対象**:
  - ネズミ、コウモリ、昆虫、および歩行者が壁に落とす「生体影」。
  - 人間の影の足元や頭部に噛み付くと、対象者はピリピリとした電撃痛と急速な倦怠感（FP喪失）を覚える。
- **防衛・弱点**:
  - 通常の銃撃・打撃は「壁を削る」だけで影魚の極薄膜をほとんど傷つけられない（突き抜け耐性）。
  - 強烈な白色フラッシュライト（1,000ルーメン以上）、紫外線照射、閃光弾（Stun Grenade）を浴びせると、光子圧により影境界が破壊され、三次元空間に薄皮状に剥がれ落ちて急速乾燥・自壊する。

## 第3章: GURPS 魔導物理・交戦データ
- **ステータス（実体化時）**:
  - ST 2, DX 14, IQ 3, HT 11, HP 4, FP 11, SM -2, 移動力 BM 8（壁面滑走）
  - 影潜伏時防護点: DR 特殊（実体弾無効・突き抜け）、実体化時: DR 0（極めて脆弱）
  - 攻撃: 影齧り（Shadow Bite: `1d-3 fat` + アストラル衰弱・FP直接吸収）
- **魔術特性**:
  - 光霊系《影渡り》《屈折》の不随意励起。

## 第4章: 食・素材利用（Class-B）
- **食文化・ジビエ**:
  - 閃光弾等で実体化させた直後に急速冷凍・水洗い。
  - 肉質はフグ皮や生湯葉に似ており、コラーゲンと旨味アミノ酸が極めて豊富。「影魚の湯引きポン酢」「カゲエイの極薄刺身」として高級料亭・居酒屋で珍重される。
- **産業・先端素材**:
  - 表皮の光子吸収粘液（シャドウ・ムチン）は、三ツ菱マナテック製「光学迷彩ステルス塗料」の主原料として高額取引。
