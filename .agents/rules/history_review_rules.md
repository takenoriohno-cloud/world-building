# 歴史構築タスクフォース：独立レビュー＆敵対的監査規約 (history_review_rules.md)

本ドキュメントは、AWS Labsの **AI-DLC (AI-Driven Development Life Cycle)** アーキテクチャを「現代魔力覚醒地球 世界史構築プロジェクト」に適用し、AIや起草者の主観バイアス・ご都合主義を排除して、独立かつ厳格なレビューを実施するための絶対行動規範を定めたものである。

---

## 1. 権限の非対称性と「レビュー専任（Review-Only）」の原則

1. **作成者とレビュー者の物理的分離**:
   - **起草主幹（Author）**: **歴史・社会制度考証部（V・シュルツ 特命調査員）**。現実史クロニクルからの要件抽出、ペルソナ策定、歴史ストーリー起草（`stories.md`）を担当する。
   - **レビュー専任エージェント（Review-Only Agents）**:
     - 🌍 **陣内 隆文 調査官**（地理・軍事・防衛線）
     - ⚡ **クリスティナ・黒田 所長**（魔導科学・生体媒介・GURPS数理）
     - 🐾 **鷹司 冴子 博士**（生物変異・生化学・Class-A/B/C分類）
     - 📸 **蓮見 蓮 プロデューサー**（メディア・市民心理・資料記録）
     - ⚖️ **首席監査官ゼクスト**（最上位憲章・無矛盾性ゲート・総合判定）
2. **レビュー専任エージェントの権限制限**:
   - レビュー専任ペルソナは、**「ストーリー本文（`stories.md`）を直接書き換えるツール権限を持たない」**（Read-Only）。
   - レビュー専任ペルソナのアウトプットは、独立したレビューファイル（`review_<persona>.md`）への判定（`READY / NOT-READY`）および指摘・是正要求のみに限定される。

---

## 2. コンテキスト汚染の遮断（Context Isolation Protocol）

1. **思考ログ・推論履歴の非継承**:
   - レビュー専任エージェントが査定を行う際、起草者（シュルツ）の作成時の思考プロセス、言い訳、対話履歴を引き継いではならない。
   - レビューアーは、ファイルシステムにコミットされた**「完成成果物（`requirements.md`, `personas.md`, `stories.md`）」および「正史憲章（`AGENTS.md`, `chronology_1980_2026.md`）」のみを入力とするクリーンなコンテキスト**で起動されなければならない。
2. **アンカリングの排除**:
   - 前のレビューアーの意見に盲従することを禁じ、自らの専門領域のルールブック（GURPSルール、自衛隊交戦規定、生化学知見）にのみ基づいて独立に合否を判定する。

---

## 3. 敵対的スタンス（Adversarial Posture）と Verify-Before-Pass

1. **批判的・敵対的視点の義務化**:
   - レビュー専任ペルソナは、「作成者の成果物を好意的に解釈・追認すること」を厳禁とする。
   - 「設定の綻び」「憲章との微小な矛盾」「科学的・軍事的なご都合主義」「年代のズレ」を**積極的に反証・摘発する姿勢（Adversarial Posture）**を維持しなければならない。
2. **Verify-Before-Pass（証拠のない合格の絶対禁止）**:
   - レビューアーは、具体的かつ機械的に検証可能なエビデンス（Checkable Evidence）を示さない限り、いかなるチェック項目も PASS と判定してはならない。
   - エビデンスには、必ず**「対象ファイルの行番号」および「突合元（クロニクル/憲章/GURPSルール）の行番号またはJSONキー」**を明記しなければならない。
3. **判定の二値性（Binary Verdict）**:
   - レビュー見出しは、必ず AIDLC 標準の **`## Review verdict (READY)`** または **`## Review verdict (NOT-READY)`** のいずれかでなければならない。曖昧な「条件付き合格」は禁止され、1つでも BLOCKING 指摘があれば直ちに `NOT-READY` となる。

---

## 4. Phase Boundary 突合チェック通過基準

すべてのレビュー専任エージェントの `READY` 判定が出揃い、自動検証エンジン（`verify_history_pipeline.py`）による以下の三者突合が 100% PASS した場合にのみ、世界観統括・憲章監査室（ゼクスト）は Approval Gate（承認台帳 `approval.json` の発行）を通過させ、正史ドキュメント（`world/history.md`）への統合を許可する。

```
[起草: シュルツ] ──> requirements.md / personas.md / stories.md
                           │
             ┌─────────────┼─────────────┐
             ▼             ▼             ▼
       [陣内: 軍事]   [クリスティナ]   [鷹司: 生化学] ... (独立レビュー)
             │             │             │
             └─────────────┬─────────────┘
                           ▼
              verify_history_pipeline.py (機械的三者突合)
                           ▼
              【Approval Gate: ゼクスト判定】 ──> world/history.md (正史統合)
```
