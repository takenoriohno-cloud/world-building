# プロジェクト・全体コンテキスト (Project Context)
<!-- .agents/rules/project-context.md -->

本ドキュメントは、「現代魔獣・幻獣生態図鑑プロジェクト」の全体アーキテクチャ、世界観コア、技術体系、およびディレクトリ構成を網羅したオンボーディング・リファレンスです。

---

## 1. プロジェクト概要
- **舞台**: 2000年にマナが復活（ミレニアム・アウェイクニング）してから26年が経過した現代（2026年）。
- **テーマ**: 現代科学・兵器文明と、突如覚醒・流入した魔獣・幻獣・魔術体系が完全並行で融合したハードリアリズム世界。
- **制作物**:
  1. 個別魔獣・幻獣生態図鑑記事（`creatures/*.md`）
  2. 現代魔術・ガープスマジック体系公式ルール集（`world/magic/rules/*.md`, `world/magic/spells/*.md`）
  3. 世界観・地理・歴史・社会制度体系（`world/geography.md`, `world/history.md`, `world/magic_theory.md`）

---

## 2. コア世界観と社会構造

| 項目 | 設定内容 |
| :--- | :--- |
| **時間軸** | 2000年マナ覚醒から26年（2026年現代）。 |
| **物理と魔法** | 完全並行・生体媒介原則。マナは電子・電磁波とは非干渉。生体・精神・魂にのみ作用。 |
| **軍事バランス** | 通常魔獣は小火器・重火器で駆除可能。魔術障壁は12.7mm徹甲弾・重火器・爆風で物理突破可能。霊体のみ専門魔法部隊が必要。竜種・神性は天災不可侵。 |
| **地理要塞網** | 世界4大アビス特異点。東京は多層同心円要塞網（コア第1〜第3同心円要塞線、壁外アウトランド）。 |
| **社会・メガコーポ** | 世界BIG5・日本4大メガコーポ（ヤマト、テイコク、三ツ菱、豊洲）が軍事・製薬・食肉を掌握。新人類（エルフ/ドワーフ/トロール）への差別とID義務。 |
| **資源分類** | 三段階分類法: Class-A（安全種・一般流通）、Class-B（要処理種・免許制ジビエ）、Class-C（汚染種・食用厳禁劇物）。 |
