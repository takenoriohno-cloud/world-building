# SDD Phase 4: 品質ゲート・整合性監査ワークフロー (`/sdd:analyze`)

本ワークフローは、実装前または実装直後に、新規設定・データが最上位憲章や既存の魔導力学・地理・法制度・戦闘バランスと完全に整合しているかを多面的に検証します。

## 実行手順

1. **憲章5大観点チェック**:
   - [ ] **進化・時間軸（26年）**: 2000年マナ覚醒から約26年の時間軸で説明可能か？（急速変異/古代覚醒/異界流入）
   - [ ] **科学・魔術並行＆生体媒介**: 電子機器と非干渉か？ マナが生体/精神/魂のみに作用しているか？
   - [ ] **軍事・弾道力学バランス**: 通常兵器で駆逐可能か？ 障壁は重火器・物理運動エネルギーで突破可能か？
   - [ ] **社会構造・新人類・メガコーポ**: 結界都市・アウトランドの地理境界、メガコーポ支配、メタヒューマン差別が反映されているか？
   - [ ] **生物・ジビエ・素材リアリズム**: 三段階分類（Class-A/B/C）に準拠しているか？ 現実の生物学・衛生・解体手順にグラウンディングされているか？

2. **魔導力学・ルールクロスチェック**:
   - `world/magic/rules/*.md` の全16ルールファイルとの照合。
   - 術士の出力上限（単独では小火器〜手榴弾程度）が守られているか。
   - マナ耐性、詠唱時間、疲労消費（FP）の整合性。

3. **矛盾検知時の挙動**:
   - 矛盾または意図しない既存設定の消失を検知した場合、**即時停止（HALT）**する。
   - `doc/audit.log` に論点を記録し、`/sdd:clarify` 形式でユーザーにすり合わせ選択肢を提示する。
