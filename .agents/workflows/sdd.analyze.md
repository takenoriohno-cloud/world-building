# SDD Phase 4: 品質ゲート・整合性監査ワークフロー (`/sdd.analyze`)
<!-- .agents/workflows/sdd.analyze.md -->

本ワークフローは、実装前または実装直後に、新規設定・データが最上位憲章や既存の魔導力学・地理・法制度・戦闘バランスと完全に整合しているかを多面的に検証します。

## 1. 前提条件 (Prerequisites)
- 作成された仕様書、実装計画、または生成されたドキュメント・エントリー。

## 2. 実行手順 (Execution Steps)

### 2.1 5専門部署・憲章監査マトリクス検証
以下の5大専門部署および憲章監査室の観点すべてでチェックを実施する：

1. **① 生態・生物調査部（Bio-Zoology Div.）**:
   - [ ] 現実の生物学・解剖学・感染症・咬合力に裏付けがあるか？
   - [ ] 三段階分類（Class-A/B/C）および現実の食品衛生・ジビエ解体手順に準拠しているか？
2. **② 地理・環境調査部（Geographical & Env. Div.）**:
   - [ ] 結界都市（多層同心円要塞網）・アウトランド・特異災害地域の地理法則に合致しているか？
3. **③ 歴史・社会制度考証部（Historical & Social Div.）**:
   - [ ] 2000年マナ覚醒（26年経過）の時間軸で説明可能か？（急速変異/古代覚醒/異界流入）
   - [ ] メガコーポ支配、新人類（メタヒューマン）差別、法制度（適性者ID等）と調和しているか？
4. **④ 魔導科学・理論研究部（Thaumaturgical Theory Div.）**:
   - [ ] 科学・魔術並行＆生体媒介原則（電子機器と非干渉）を守っているか？
   - [ ] 魔術出力限界（人間単独は小火器〜手榴弾程度）、全16ルール・全15系統呪文と整合しているか？
   - [ ] 軍事・弾道力学バランス（通常兵器で駆逐可能、障壁は重火器・物理運動エネルギーで突破可能）を守っているか？
5. **⑤ 視覚・音響・資料記録部（Visual, Acoustic & Multi-Media Div.）**:
   - [ ] 生態写真・標本写真のプロンプト設計およびアセット格納（`assets/`）が計画されているか？
   - [ ] Mermaid構造図が構文エスケープ規則および図種別指定（`flowchart TD` / `LR` / `BT` / `sequenceDiagram`）に準拠しているか？
   - [ ] 鳴き声・警戒音・共鳴波の音響周波数データ（Hz/kHz/dB）が学術的に設計されているか？
6. **【世界観統括・憲章監査室】（Charter Audit Office）**:
   - [ ] `AGENTS.md` 最上位憲章および過去の解決済みQ&Aとの衝突・矛盾がないか？

### 2.2 矛盾検知時の挙動
- 矛盾または意図しない既存設定の消失を検知した場合、**即時停止（HALT）**し、`/sdd.clarify` を発動する。

## 3. 完了条件 (Done Definition)
- 全監査マトリクスをパスし、重大な衝突がないことが確認されていること。

## 4. 次フェーズへの移行 (Next Phase Handoff)
- 実装前の場合は **Phase 5: 実装 (`/sdd.implement`)** へ進む。
- 実装後の場合は **Phase 6: 監査・永続化 (`/sdd.audit`)** へ自動移行する。
