# SDD Phase 5: 実装・生成ワークフロー (`/sdd:implement`)

本ワークフローは、事前承認された仕様書（`specs/`）およびタスクリスト（`tasks/`）に基づき、図鑑記事（`creatures/*.md`）や世界設定資料（`world/*.md`）の実装・生成を行います。

## 実行手順

1. **仕様とタスクの読み込み**:
   - 仕様書（`.specify/specs/<feature_name>.spec.md`）
   - タスクファイル（`.specify/tasks/<feature_name>.tasks.md`）
   - フォーマットテンプレート（魔獣の場合は `TEMPLATE.md`、設定の場合は該当テンプレート）

2. **外部調査・科学グラウンディング（義務）**:
   - `search_web` ツールを活用し、対象生物の原種データ（骨格、咬合力、感染症リスク等）や弾道データ、地理データを調査。

3. **実装・ファイル生成**:
   - 仕様書とテンプレートに定義された全項目を一切の省略なく記述。
   - 学術的リアリズム（観察記録、解剖、軍事報告、ジビエ料理人の証言）を取り入れたトーン＆マナーを徹底。

4. **品質検証**:
   - 生成後に `/sdd:analyze` を実行し、全憲章項目の遵守を確認。
