# SDD Phase 5: 実装・生成ワークフロー (`/sdd.implement`)
<!-- .agents/workflows/sdd.implement.md -->

本ワークフローは、事前承認された仕様書（`specs/`）およびタスクリスト（`tasks/`）に基づき、図鑑記事（`creatures/*.md`）や世界設定資料（`world/*.md`）の実装・生成を行います。

## 1. 前提条件 (Prerequisites)
- 仕様書（`.specify/specs/<feature_name>.spec.md`）
- タスクファイル（`.specify/tasks/<feature_name>.tasks.md`）
- フォーマットテンプレート（`TEMPLATE.md` または該当テンプレート）

## 2. 実行手順 (Execution Steps)
1. **外部調査・科学グラウンディング（義務）**:
   - `search_web` ツールを活用し、原種生物データや弾道データ、実在インフラを精密調査。
2. **実装・ファイル生成**:
   - 仕様書とテンプレートに定義された全項目を一切の省略なく記述。
   - 学術的リアリズム（観察記録、解剖、軍事報告、ジビエ料理人の証言）を取り入れたトーン＆マナーを徹底。
3. **タスク進捗の更新**:
   - 完了したタスクのチェックボックスを更新（`[x]`）。
4. **自動品質ゲート検査**:
   - 生成完了直後に自動的に **Phase 4: 品質ゲート・整合性監査 (`/sdd.analyze`)** を実行。

## 3. 完了条件 (Done Definition)
- 対象ファイルが過不足なく作成され、タスクが完了し、整合性チェックをパスしていること。

## 4. 次フェーズへの移行 (Next Phase Handoff)
- 実装と品質ゲート完了後、自動的に **Phase 6: 監査・永続化ワークフロー (`/sdd.audit`)** へ移行する。
