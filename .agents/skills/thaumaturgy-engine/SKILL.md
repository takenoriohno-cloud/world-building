# 魔導力学・呪文設計スキル (thaumaturgy-engine)

本スキルは、本プロジェクトにおいて魔導理論、呪文、魔導障壁、マナ環境を設計・検証する際の専門ガイダンスおよびルールエンジンです。

## 1. 魔導力学の根幹原則
- **生体媒介原則**: マナは電子回路・通信波等の無機物理現象には干渉せず、生体組織、神経系、魂・アストラル体にのみ作用する。
- **マナの非物質性**: 検出・単離可能な物理粒子ではなく、生体との共鳴・波長変化としてのみ観測される。
- **人間術士の出力限界**:
  - 単独詠唱での火力は「小火器〜手榴弾程度」が上限。
  - 戦略級破壊は単独では不可能。大儀式や巨大マナ結晶・結界インフラの補助が必要。
  - 術士の主たる真価は「支援・探知・治癒・霊体駆逐・妨害」にある。

## 2. 魔導障壁の物理相互作用
- **力場構造**: マナ障壁は指向性エネルギー偏向場であり、小口径弾の運動エネルギーを散逸させる。
- **限界飽和と突破**: 12.7mm徹甲弾、成形炸薬弾（対戦車ミサイル）、航空爆風などの圧倒的物理運動エネルギーによって障壁は飽和・破断する。

## 3. 4大魔術体系
1. **理論魔導学派 (Hermetic Mage)**: 数理モデル、四大元素（地水火風）、工業的魔導。
2. **伝統・儀式学派 (Shamanism / 神道 / 修験道)**: 自然精霊・祖霊・式神使役。メイジと同等の実効出力を発揮。
3. **上位次元契約魔術 (Plane Pact)**: 精霊王・神格との対等または従属誓約。
4. **深淵・邪神呪術 (Abyss Sorcery)**: クトゥルフ型の外なる神・アビスの波長受信。精神汚染と肉体変異を伴う禁忌。

## 4. 呪文・ルール照合
- 呪文・ルールを策定・参照する際は、必ず `world/magic/rules/*.md`（全16ルール）および `world/magic/spells/*.md`（全15系統呪文）と照合すること。
