# 魔獣・幻獣設計スキル (creature-design)

本スキルは、本プロジェクトにおいて魔獣・幻獣のエントリーを設計・作成する際の専門ガイダンスおよびチェックリストです。

## 1. 生物学的・解剖学的リアリズム (グラウンディング)
- **原種生物の調査**: 変異元となる既存生物（例: ニホンイノシシ、ヒグマ、オオタカ等）の現実の体重、骨格、筋繊維構造、咬合力を `search_web` で事前調査。
- **変異メカニズムの論理化**: 2000年マナ覚醒から約26年でどのように生体変異（骨質硬化、器官肥大、体液変化等）が起きたかを生物学的に説明。
- **感染症・寄生虫リスク**: E型肝炎、旋毛虫（トリヒナ）、マダニ媒介感染症などの現実的リスクと、マナ変異による固有リスクを両論併記。

## 2. 軍事・弾道力学対処バランス
- **実弾口径との対比**:
  - `5.56mm NATO (SS109 / 5.56×45mm)`: 初速約930m/s、運動エネルギー約1,700〜1,800J。小・中型魔獣の非装甲部位に有効。
  - `7.62mm NATO (7.62×51mm)`: 初速約830m/s、運動エネルギー約3,500J。大型魔獣・軽度変異外殻の貫通に有効。
  - `12.7mm重機関銃 (12.7×99mm / .50 BMG)`: 初速約900m/s、運動エネルギー約18,000J。重装甲変異種・障壁の物理的粉砕に必須。
  - `12 Gauge Slug / 散弾`: 近接での強烈なストッピングパワー。
- **戦術的対処**: 弱点部位（目、喉、関節部、吸気器官等）と有効射程、射撃戦術を記載。

## 3. ジビエ・食・素材利用（三段階分類法）
- **Class-A (安全種)**: 一般流通可能。肉質、風味、推奨調理法（ステーキ、鍋等）。
- **Class-B (要処理種)**: 要専門免許。放血、臭腺除去、特定器官の切除手順。
- **Class-C (汚染種)**: 食用厳禁。バイオハザード指定および廃棄プロトコル。
- **素材採取**: 骨、牙、角、毛皮、分泌液等の工業・医療・防護装備への用途。
