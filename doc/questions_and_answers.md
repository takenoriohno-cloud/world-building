## Ⅰ. 世界法則編（時間軸・マナ相互作用・資源分類）

### Q1. 【進化速度と歴史の整合性】2000年マナ覚醒から26年のタイムスケール
- **論点**: 西暦2000年のマナ覚醒からわずか26年で、多種多様な魔獣・生態系や新人類（メタヒューマン）が存在する生物学的・歴史的理由。
- **提示された選択肢**:
  - **A)** 急速変異説のみ（既存動植物が高濃度マナで個体・数世代で変異）
  - **B)** 古代覚醒説のみ（マナ希薄期に地下・深海で眠っていた古代幻獣が復活）
  - **C)** 異界・深淵流入説のみ（空間の歪み・アビス特異点から別次元生態系が侵入）
  - **D) 【採択】ハイブリッド複合モデル**: A・B・Cの3要因が同時に複合発生。
- **決定事項（正史）**:
  1. **急速マナ変異**: 既存の動植物が数世代・個体単位で魔獣化。人間もエルフ・ドワーフ等の新人類（メタヒューマン）へ急速変異。
  2. **古代種の覚醒**: 地下空洞・深海・極地で休眠していた古代種・霊的生物が一斉活動開始。
  3. **異界アビス侵食**: 空間特異点から異次元生態系が流入し、常時異常な「特異災害指定地域（アビス汚染域）」を形成。

### Q2. 【科学インフラ vs 魔法・マナの物理的干渉】
- **論点**: マナや魔法現象が、現代の電子機器、通信網、送電網、コンピュータ等の科学技術インフラにどう影響するか。
- **提示された選択肢**:
  - **A)** 電磁パルス（EMP）干渉型（マナが高濃度になると電子機器がショート・故障する）
  - **B)** 物理法則置換型（マナが物理定数を書き換え、火薬や燃焼機関が作動しなくなる）
  - **C) 【採択】完全並行＆生体限定作用型**: マナは電子・電磁気とは非干渉。生体組織・精神神経・魂にのみ作用。
- **決定事項（正史）**:
  - **物理・電磁気非干渉**: シリコン半導体、通信波、送電網は正常稼働。
  - **生体媒介の徹底**: マナは生体・魂にのみ作用。電脳魔術・テクノマジックは「術士の脳・神経系・生体電位」をジャック・同調して端末を操作する技術であり、電子回路に直接マナが流れているわけではない。
  - **魔力の非物質性**: マナや魔力は物理的粒子・元素として単離検出されない。

### Q3. 【食・素材利用・バイオハザード分類】
- **論点**: 討伐・捕獲した魔獣の肉・血液・骨・皮の利用法、およびマナ摂取による生体リスク管理。
- **提示された選択肢**:
  - **A)** 完全食用不可（全魔獣肉にマナ毒があり、廃棄・焼却のみ）
  - **B)** 魔力抜き必須（科学的・工業的「魔力中和処理」を行えば全て可食）
  - **C) 【採択】三段階法制分類法**: 「魔力抜き」という万能処理は存在せず、生体毒・呪術的リスクに応じた3区分。
- **決定事項（正史）**:
  1. **Class-A（安全種）**: 生体毒・呪術的危険がなく、一般流通・家畜養殖が認可された種（例: 低マナ角鹿、変異食用鳥など）。
  2. **Class-B（要処理種 / 要免許ジビエ）**: 特殊な毒腺、寄生虫、呪術的下処理（特定部位の切除・放血・塩清め等）を要する種（例: 剛毛巌猪など）。国家資格を持つ専門調理師・解体師のみ調理可能。
  3. **Class-C（汚染種 / 食用禁止・劇物）**: 摂取すると致命的肉体変異、精神崩壊、猛毒、呪いをもたらす種（深淵アビス種、精神汚染種等）。完全食用禁止・バイオハザード指定。

### Q4. 【現代兵器 vs 魔獣の力関係と討伐体制】
- **論点**: 通常の銃火器や軍隊・警察火器は魔獣に通用するのか、魔法部隊との役割分担はどうなるか。
- **提示された選択肢**:
  - **A)** 現代兵器完全有効（全魔獣に銃火器が効く）
  - **B)** 現代兵器無効（魔法でしか魔獣を倒せない）
  - **C)** 魔法付与兵器主流（全弾薬に魔力を付与して戦う）
  - **D) 【採択】クラス・特性別区分モデル**:
- **決定事項（正史）**:
  1. **通常魔獣**: 現代通常兵器（5.56mm/7.62mm小銃、12.7mm重機関銃、機関砲）で十分駆除可能。
  2. **魔術障壁保有種**: 小口径弾は弾かれるが、重火器（12.7mm徹甲弾、対戦車ミサイル、爆風運動エネルギー）で障壁ごと粉砕・突破可能。
  3. **霊体・精霊・ゴースト（非物理存在）**: 物理攻撃完全無効。警察・自衛隊の「専門魔法部隊（術士・陰陽師・エクソシスト）」が対処。
  4. **高知能竜種（ドラゴン）・神性存在**: 軍隊でも勝てない絶対不可侵の天災指定存在。

## Ⅲ. 魔術理論・社会構造編（魔術出力・メガコーポ・新人類）

### Q6. 【人間の行える魔法の出力規模と体系分類】
- **論点**: 人間の魔術師・術士が行使できる魔法の限界値と、世界における魔術の学派・体系。
- **決定事項（正史）**:
  - **出力規模の基準**: **『ガープス・マジック（GURPS Magic）』基準**を採用。
    - 単独術士の直接火力は「小火器〜手榴弾程度」。街を吹き飛ばすような戦略魔法は単独では不可能。
    - 障壁は重火器で突破可能。支援・探知・治癒・霊体除霊において絶大な真価を発揮する。
  - **4大体系分類**:
    1. **理論魔導学派（ハーメチック・メイジ）**: 数理モデル・工業化・四大元素精霊使役。
    2. **伝統・儀式学派（シャーマニズム・神道・修験道）**: 信仰・習慣・自然精霊・式神使役（※メイジと同等出力）。
    3. **上位次元契約魔術（プレーン・パクト）**: 精霊王・動物王・秩序/混沌の神格との誓約（エルリック型）。
    4. **深淵・邪神呪術（アビス・ソーサリー）**: 旧支配者・外なる神の波長受信、精神汚染・狂気・変異を伴う禁忌呪術（クトゥルフ型）。

### Q9. 【都市精霊とストリートシャーマニズムの具現力学】
- **論点**: アメリカ等のメガプレックスにおけるストリートシャーマンが召喚する「都市精霊（街路霊・アスファルト/スモッグ精霊）」の霊的・物理的性質と交戦バランス。
- **決定事項（正史）**:
  - **ハイブリッド具現構造**: 精霊のコアはアストラル霊体（非物理）であり、生体組織・魂を通じてシャーマンと結合。現界時に都市の廃棄物（アスファルト、コンクリート、廃鉄筋、煤煙、ネオン管）を凝集させて物理シェル（外殻 DR 7）を形成する。
  - **戦闘バランス**: 霊体状態では通常兵器無効。具現化状態では小口径弾（9mm/5.56mm）を減衰・跳弾するが、重機関銃（12.7mm M2 / 17,000J）やスラッグ弾の圧倒的運動エネルギー、および対霊魔術（霊撃・ディスペル）で外殻ごと粉砕・消滅可能。
  - **資源・食用区分**: **Class-C（汚染・霊体種 / 非可食）**。消滅時に肉は残らないが、中心部に残る「アーバン・エーテル・スラグ（凝縮都市マナ残滓）」が電脳魔導やサイバーウェアの絶縁触媒として裏市場で高額取引される。

### Q11. 【精霊界からの異界流入種と自然共生精霊の生態力学】

- **決定事項（正史）**:
  - **物質・マナ共生代謝**: 精霊界から越境した微小霊体が、ヨーロッパ等の原生林の物理的朝露・植物蒸散水分とアストラル結合し、昼間は「浮遊水滴球」、夜明け前は「体長12cmの半透明小人（SM -5）」として活動。
  - **環境守護・治癒役割**: 攻撃能力は持たず（Threat Level I）、水霊系《小治癒》《清浄化》を不随意励起して周囲の森林植物の成長と薬効を飛躍的に高める。
  - **資源・法制区分**: **Class-A（安全種 / 非破壊的採取資源・保護指定）**。精霊本体の殺傷・捕獲は欧州自然保護条約で厳禁。毎朝葉上に分泌される「朝露エキス（Dewdrop Nectar）」のみが極上の疲労回復・生薬原料として非破壊採取・流通される。
