## 1. 詳細略年表（2000年〜2026年）

| 年月 | 歴史的事件 | 社会・軍事・生活への影響 |
| :--- | :--- | :--- |
| **2000年1月1日** | **ミレニアム・アウェイクニング（マナ覚醒）** | 地球規模で霊的エネルギー（マナ）が噴出。既存生物の急速変異、人間におけるメタヒューマン（新人類）誕生、異界特異点の発生。 |
| **2001年〜2004年** | **第一次魔獣災害・壁面防衛戦** | 各国で暴走した変異獣による都市壊滅。通常軍備による掃討作戦と、主要都市を囲む防護壁・結界化計画（結界都市構想）の始動。 |
| **2005年〜2010年** | **結界都市体制の確立・法整備** | 都市とアウトランドの物理分断完了。魔獣の駆除・素材回収を担う認可民間軍事会社（PMC）およびプロハンター制度が法制化。 |
| **2012年〜2018年** | **メガコーポの台頭と新人類問題** | マナ研究を独占する多国籍メガコーポが巨大な権力を獲得。水面下での非人道的人体実験、新人類（エルフ・ドワーフ等）に対する社会的差別・隔離が激化。 |
| **2020年〜2024年** | **魔獣資源分類法（三段階制度）の制定** | 安全種（Class-A）、要処理種（Class-B）、汚染種（Class-C）の法的基準が確立。高知能竜種および神性存在に対する「絶対不可侵条約」の締結。 |
| **2026年（現在）** | **現代・生態図鑑編纂プロジェクト** | 結界都市内の高度情報化社会と壁外の苛烈な魔境が定着。人類の生存権拡大と資源探求のため、網羅的な生態図鑑の編纂が国家・学会主導で進む。 |

## 2. 主要社会勢力と治安体制

### 2.1 防衛・治安組織
- **自衛隊 / 各国正規軍**: 通常兵器（小銃・重火器・戦車・爆撃機）による外壁防衛および大規模掃討作戦を担当。
- **警察・特科魔法部隊**: 都市内部の治安維持、および通常兵器が無効な霊体・精霊・ゴースト災害への緊急対処。
- **民間軍事会社（PMC）/ 認可ハンターギルド**: アウトランドでの素材採取、護衛、害獣駆除を受託する民間プロフェッショナル。

### 2.2 メガコーポレーション（魔導複合企業）
- 結界維持装置、防護壁素材、生体医薬品、先端魔導研究を牛耳る超巨大企業群。利益とマナ利権のために裏で非合法活動を展開。

### 2.3 新人類（メタヒューマン）
- 2000年の覚醒以降、人間から変異・誕生した特異生体を持つ人々。身体能力や魔力感受性に優れるが、結界都市内では根強い偏見や差別、企業による生体実験の標的となるリスクに晒されている。
