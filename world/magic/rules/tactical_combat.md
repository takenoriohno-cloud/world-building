# 戦術戦闘・マニューバ・能動防御・格闘力学 (Tactical Combat, Maneuvers & Defense Mechanics)

本ドキュメントは、現代（2026年）における対魔獣・対テロ・対術士戦闘の1秒ターン制戦術手順、全14大戦闘マニューバ、命中部位・トリック攻撃、組みつき・関節技・体当たり、および3大能動防御（よけ・受け・止め）を規定した実戦戦闘基準書です。

---

## 1. 戦闘ターンの基本構造 (Combat Sequence & Timing)

現代魔獣戦闘における時間は **1ターン＝1秒** の厳密な実時間スケールで進行する。

### 1.1 行動順（Initiative）の決定
- **基本速度（Basic Speed: BS）順**: 各キャラクターは自身のBS（小数点以下含む）が高い順に能動ターンを開始する。
- **同値の場合**: 敏捷力（DX）が高い側が先攻。DXも同値ならダイス勝負。

### 1.2 能動ターン（Turn）の流れ
1. **マニューバの宣言**: 自手番の開始時に1つの「戦闘マニューバ」を選択する。
2. **ステップ移動（Step）**: 多くのマニューバで 1ヤード（約1m）のステップ移動が可能。
3. **主行動の実行**: 射撃、白兵攻撃、詠唱、リロード等。
4. **ターンの終了**: 次の自手番が回ってくるまで、敵の攻撃に対して「能動防御」を試みることができる。

## 2. 14大戦闘マニューバ一覧 (The 14 Combat Maneuvers)

| マニューバ名 | 移動能力 | 攻撃・行動内容 | 可能な能動防御 | 現代実戦での運用シチュエーション |
| :--- | :---: | :--- | :---: | :--- |
| **〈何もしない〉 (Do Nothing)** | 移動不可 | 行動なし。精神的・肉体的ショック・スタンからの回復判定（HTまたはIQ）。 | 制限あり (防御-4) | スタン直後、不意打ちを受けた瞬間。 |
| **〈移動〉 (Move)** | 全力移動 (BM) | 最大移動力で移動。ダッシュ・退避・遮蔽物への飛び込み。 | 通常通り (よけのみ) | 魔獣の突進からの緊急退避、突入地点への疾走。 |
| **〈姿勢変更〉 (Change Posture)** | 移動不可 | 直立・屈み・膝立ち・座り・伏せ・這いの相互切り替え（1秒）。 | 通常通り | 射撃姿勢（伏せ）への移行、転倒からの起き上がり。 |
| **〈狙い〉 (Aim)** | ステップのみ | 射撃武器で照準をつける。1秒でAccボーナス、追加1秒ごとに+1（最大+2）。 | 防御すると照準喪失 | スナイパーによる魔獣急所狙撃、精密射撃。 |
| **〈観察〉 (Evaluate)** | ステップのみ | 白兵戦で相手の隙を伺う。1秒ごとに次ターンの白兵命中+1（最大+3）。 | 通常通り | 刀剣・格闘での間合いの駆け引き、カウンター狙い。 |
| **〈攻撃〉 (Attack)** | ステップのみ | 近接白兵攻撃、または射撃攻撃を1回行う。 | 通常通り | 最も標準的な実戦交戦行動。 |
| **〈フェイント〉 (Feint)** | ステップのみ | 相手の防御を崩す技能勝負。勝利度分、次ターンの相手防御を低下。 | 通常通り | 障壁を持つ敵や高敏捷魔獣の防御崩し。 |
| **〈全力攻撃〉 (All-Out Attack)** | 前進半歩〜半移動 | **能動防御を完全放棄**し、攻撃を極大強化（下記4オプションから選択）。 | **完全不可 (防御 0)** | 隙だらけの魔獣へのトドメ、捨て身の突撃。 |
| **〈移動攻撃〉 (Move & Attack)** | 全力移動 (BM) | 移動しながら射撃・白兵攻撃を行う（命中-4、実効技能上限9）。 | よけ・止めのみ | 走り抜けざまの掃射、機動強襲。 |
| **〈全力防御〉 (All-Out Defense)** | ステップ or 半移動 | 攻撃を一切行わず、防御に専念（防御値+2、または2回防御）。 | **極大強化 (+2/2回)** | 弾幕制圧下の耐え、味方の詠唱完了までの時間稼ぎ。 |
| **〈集中〉 (Concentrate)** | ステップのみ | 呪文の詠唱、精神集中、超能力行使。ダメージを受けると集中中断判定。 | 通常通り (-3修正) | 術士の主たる行動。防護結界や火球の練成。 |
| **〈準備〉 (Ready)** | ステップのみ | 武器の抜刀・収納、弾倉交換（リロード）、道具・手榴弾の準備。 | 通常通り | タクティカルリロード、呪符・ポーションの取り出し。 |
| **〈待機〉 (Wait)** | 行動による | 「敵が角から出たら射撃」等のトリガーを設定し、割り込み行動を準備。 | 通常通り | 部屋クリアリング、待ち伏せアンブッシュ。 |
| **〈すり抜け〉 (Evade)** | 全力移動 (BM) | 敵の占有ヘクス（間合い）を強引に走り抜ける（敏捷勝負）。 | 通常通り | 包囲網の強行突破、後衛術士への肉薄。 |

### 2.1 全力攻撃（All-Out Attack）の4大オプション
1. **必中の一撃 (Determined)**: 攻撃判定に **+4 ボーナス**（射撃時は +1）。
2. **2回攻撃 (Double)**: 同一武器または両手の武器で **2回連続攻撃**。
3. **フェイント即攻撃 (Feint)**: フェイント直後に即座に攻撃。
4. **渾身の一撃 (Strong)**: 白兵ダメージに **+2点（またはダイス1個につき+1点）のボーナス**。

## 3. 命中部位・急所・トリック攻撃 (Hit Locations & Tactical Strikes)

### 3.1 命中部位修正と負傷特性
| 命中部位 | 命中修正 | 装甲DR | 負傷特性・特異ダメージ倍率 | 現代魔獣戦での戦術的意義 |
| :--- | :---: | :---: | :--- | :--- |
| **胴体 (Torso)** | **0** | 通常 | 通常ダメージ。標準部位。 | 最も狙いやすく安定した射撃部位。 |
| **急所・バイタル (Vitals)** | **-3** | 通常 | **刺突(imp)・貫通(pi)は負傷 ×3倍**。大出血。 | ライフル弾での心臓・肺・生体マナ核狙撃。 |
| **頭蓋・脳 (Skull/Brain)** | **-7** | DR+2 | **全属性負傷 ×4倍**。即座の気絶・HT-10即死判定。 | 致命的ノックアウト。骨性頭蓋の貫通が必要。 |
| **顔面 (Face)** | **-5** | なし | 脳への貫通あり。感覚器破壊（失明判定）。 | 硬質ヘルメットのバイザー部・装甲隙間狙撃。 |
| **首・頸動脈 (Neck)** | **-5** | 通常 | **斬撃(cut)は負傷 ×2倍**、窒息・大出血。 | 斬撃武器での首刎ね（Decapitation）。 |
| **腕・手 (Arm/Hand)** | **-2 / -4** | 通常 | 一定ダメージ（HP/2）で **腕不随（武器落とし）**。 | 武器や爪・生体火炎放射器の機能無力化。 |
| **脚・足 (Leg/Foot)** | **-2 / -4** | 通常 | 一定ダメージ（HP/2）で **脚不随（転倒・移動不能）**。 | 突進系大型魔獣の脚部破壊・機動力奪還。 |
| **目 (Eyes)** | **-9** | **DR 0** | **刺突・貫通で脳直撃（×4倍）**。失明。 | 超硬質甲殻魔獣の唯一の弱点スナイピング。 |

### 3.2 トリック攻撃 (Deceptive Attacks)
- 熟練の近接戦闘員が放つ、予測不能な軌道の攻撃。
- **力学**: 自身の白兵技能に **-2 のペナルティを課すごとに、相手の能動防御判定に -1 のペナルティ** を与える（-4で相手防御-2、-6で相手防御-3）。

## 4. 白兵格闘・組みつき・制圧関節技 (Grappling, Wrestling & Close Combat)

### 4.1 組みつき力学 (Grappling Flow)
1. **組みつき攻撃**: 〈格闘〉〈レスリング〉または〈柔道〉で命中判定。相手は通常通り能動防御可能。
2. **組みつき状態の効果**:
   - 組みつかれた側は **敏捷力（DX）に -4 のペナルティ**。
   - 移動力はゼロになり、ステップ移動も不可。
3. **振りほどき (Break Free)**: 組みつかれた側は自手番に **ST勝負（またはレスリング技能勝負）** を挑み、勝利すれば脱出可能。

### 4.2 制圧・関節技・サブミッション
| 技名称 | 判定方法 | 効果・生体ダメージ | 現代運用・対人・対新人類制圧 |
| :--- | :--- | :--- | :--- |
| **倒す (Takedown)** | ST/柔道/レスリング勝負 | 相手を地面に叩きつけて **伏せ状態（転倒）** にする。 | 暴徒化した変異体・新人類の制圧。 |
| **押さえこみ (Pin)** | ST勝負（相手伏せ時） | 相手の全行動を封じ、完全に行動不能にする。 | 警察官・ハンターによる魔獣生け捕り・拘束。 |
| **チョークホールド (Choke)** | 毎ターンST勝負 | **毎ターン 1d 叩きダメージ（DR無視）** + 窒息FP喪失。 | 術士の詠唱阻止、非致死絞殺。 |
| **腕関節技 (Arm Lock)** | 柔道/レスリング勝負 | **相手のSTを超える勝利度ごとに 1点ダメージ**（骨折）。 | 銃器・刀剣を奪い、腕をへし折る。 |
| **四肢・首捻転 (Wrench Limb)** | ST勝負 | 骨・関節の破壊。ST勝負の勝利度に応じた重傷。 | 巨体トロールや大型猟犬の首折り。 |
| **体当たり (Slam)** | 移動速度×STの叩き | 突進による衝突ダメージ + 転倒判定。 | 防暴盾を持った機動隊・大型魔獣の突撃。 |

## 5. 3大能動防御と戦闘中のさらなる努力 (Active Defenses & Extra Effort)

### 5.1 3大能動防御（よけ・受け・止め）
| 防御種別 | 計算式 | 特徴・制限 |
| :--- | :--- | :--- |
| **よけ (Dodge)** | $\text{BM} + 3 + \text{DB}$ | 回数制限なし。銃撃・爆風に対しても使用可能な唯一の防御。 |
| **受け (Parry)** | $(\text{武器技能} / 2) + 3 + \text{DB}$ | 武器または素手で攻撃を弾く。1ターンに同武器で1回（格闘・フェンシングは複数回）。 |
| **止め (Block)** | $(\text{〈盾〉技能} / 2) + 3 + \text{DB}$ | 盾で攻撃を受け止める。1ターンに1回。 |

### 5.2 戦闘中のさらなる努力 (Extra Effort in Combat)
命の危機において、**疲労点（FP）を 1点消費** して極限の能力を発揮する：
- **渾身の防御 (Feverish Defense)**: 能動防御判定に **+2 のボーナス**。
- **渾身の一撃 (Mighty Blows)**: 白兵攻撃のダメージに **+2点（または+1点/ダイス）**。
- **電光石火 (Flurry of Blows)**: トリック攻撃や2回攻撃のペナルティを半減。
- **超大跳躍踏み込み (Great Lunge)**: ステップ移動距離を 2ヤードに倍増して攻撃。
