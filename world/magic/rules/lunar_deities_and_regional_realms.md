# 月輪神性恩寵・辺境要塞環境・真空崩壊力学 (Lunar Deities, Frontier Realms & Vacuum Mechanics)

本ドキュメントは、「現代魔獣・幻獣生態図鑑」における**6大月輪神性信仰・神性恩寵（Divine Powers）体系**、**境界要塞都市・過酷アウトランド環境力学**、および**大崩壊（Cataclysm）の歴史的教訓と真空魔法力学**を定めた正史ルールアーカイブである。

---

## 1. 6大月輪神性信仰と神性恩寵（Divine Powers）体系

2000年のマナ覚醒以降、伝統宗教の再解釈やアビス特異点の波長同調により、天球の運行と霊的波長を結びつける「6大月輪神性（Six Lunar Aspects）」への信仰が世界各地および日本国内の術士・ハンター・法執行機関の間で定着した。

術士が特定の月輪神性に帰依し、戒律を遵守することで、ガープス基準の**神性恩寵（Divine Favor / パワー投資）**として奇跡的加護を発現させることができる。

```
                    【6大月輪神性スペクトラム】
                      
             [銀の月 (知識・秩序・治癒)] ── 法執行・医療・浄化
            ／                                        ＼
[青の月 (冷徹・理知・電脳)]                     [緑の月 (自然・豊穣・動植物)]
         │                                              │
[黒の月 (夜闇・暗殺・死者安息)]                 [双子の月 (幻惑・二面性・変身)]
            ＼                                        ／
             [赤の月 (武勇・剛力・火炎)] ── PMC・突入・破壊
```

## 2. 境界要塞都市と過酷アウトランド環境力学

壁外（アウトランド）およびアビス特異点周辺には、現代科学の常識を超えた過酷な環境が広がっており、侵入部隊・調査団には専門装備と環境判定が義務付けられている。

### 2.1 境界要塞ゲート（アリクビ型要塞都市モデル）
- **検問・除染プロトコル**: 壁外から結界都市（インナー・ゾーン）へ帰還するすべての部隊・車両・魔獣素材は、3段階除染シャワー（高圧マナ中和剤＋紫外線照射）と「魂の汚染度スキャン」を通過しなければならない。
- **汚染度超過時の隔離**: 汚染度（Corruption）が閾値（25点以上）に達した者は、即座に特異検疫隔離棟に送致される。

### 2.2 3大過酷アウトランド環境の判定ルール

```
┌─────────────────────────────────────────────────────────────┐
│                 アウトランド3大過酷環境力学                  │
├─────────────────────────────────────────────────────────────┤
│ ① 未踏熱砂特異点   ── 高熱・マナ渇水・幻覚砂嵐 (HT-3判定) │
│ ② 大湿圏・腐食泥濘 ── 有毒瘴気・防護服劣化・移動力半減 (HT-2)│
│ ③ 無限回廊山脈     ── 空間歪曲・ナビ不能・超硬度鉱脈 (IQ-4)│
└─────────────────────────────────────────────────────────────┘
```

1. **未踏熱砂特異点 (Scorched Abyss Waste)**:
   - **マナ渇水**: 周囲のマナ濃度が急激に乱高下し、呪文詠唱時の消費FPが2倍。
   - **熱砂と幻覚**: 日中の気温が50℃を超え、1時間ごとに【HT-3】判定。失敗すると1d6の疲労ダメージと砂嵐による視覚幻覚（IQ-2ペナルティ）。
2. **大湿圏・有毒泥濘域 (Toxic Great Mire)**:
   - **有毒瘴気**: 吸入すると毎時【HT-2】判定。失敗で呼吸器不全（1d6毒ダメージ＋FP-2）。
   - **腐食泥濘**: 足場が極端に悪く基本移動力（Move）半減。酸性泥により通常ブーツ・車両タイヤのDRが毎時間1ずつ減少。
3. **無限回廊山脈 (Infinite Corridor Ridges)**:
   - **空間歪曲**: 地形が位相幾何学的に歪んでおり、通常のコンパス・GPSが完全無効。【ナビゲーション/TL8 -4】または【魔導方位感知】技能判定が必要。失敗すると同一エリアを周回し時間を浪費する。
   - **超硬度マナ鉱脈**: 周囲の岩石がオリハルコン/ミスリル等の微小結晶を含み、防護点（DR 30〜50）。通常の発破・削岩機では貫通不能。

## 3. 大崩壊（Cataclysm）の歴史的教訓と真空魔法力学

### 3.1 第一次マナ覚醒時の「大崩壊」
2000年1月1日のミレニアム・アウェイクニング直後、マナの局所的急膨張によって旧式インフラが崩壊し、大都市の一部が異次元断層へと呑み込まれた現象を「**大崩壊（The Great Cataclysm）**」と呼ぶ。この教訓から、現代の結界都市は多層防護壁と地下調節池要塞網によってマナ圧力を分散・逃す構造となっている。

### 3.2 真空魔法力学（Vacuum Evacuation Magic）

大気系および空間系の複合魔術として、密閉空間や局所空間の気圧・酸素を瞬時に排除する「真空魔法」が存在する。対人・対魔獣戦において極めて致命的な威力を発揮する。

```
【真空球（Vacuum Sphere）発現メカニズム】
術士詠唱 ──► 半径3mの球状気圧を瞬時に0.01気圧まで強制減圧
             ├── 物理衝撃: 周囲大気の突入による爆縮波（2d6 叩きダメージ / 破砕音）
             ├── 生体影響: 肺胞破裂・血液沸騰（毎秒 1d6 直接HPダメージ / 防護点無視）
             └── 燃焼遮断: 範囲内の銃火器発射・火炎魔術が完全不発
```

- **呪文諸元**:
  - **系統**: 空気系 / 空間ゲート系 複合
  - **詠唱時間**: 2秒
  - **消費エネルギー**: 基本 4 FP（維持 2 FP/秒）
  - **効果**:
    1. **直接ダメージ**: 範囲内の生体は防護点（DR）を無視して毎秒【1d6 HP】の減圧・窒息ダメージ。
    2. **爆縮衝撃**: 展開時に大気突入による【2d6 叩き】ダメージおよび転倒判定（ST-3）。
    3. **火器・内燃機関停止**: 範囲内の酸素が枯渇するため、ガソリン車・火薬式銃火器の燃焼が停止（電気式・バッテリー駆動兵器のみ作動可能）。
    4. **防御突破特性**: 通常の魔導障壁（物理弾・熱線用）を透過し、障壁内部の空気を直接抜くことが可能。

## 4. 本アーカイブの適用基準

1. **神性恩寵の運用**: 信仰を持つPC・NPCは、対応する月輪神性の戒律（-5〜-10CP）を取得することで、恩寵パワーを発動できる。
2. **アウトランド遠征**: 未踏熱砂、大湿圏、無限回廊への進入時は、本ドキュメント記載の環境判定を厳格に適用する。
3. **真空魔法の危険性**: 密閉結界内での真空魔法使用はバイオハザード・特異災害指定級の重大戦術呪文として扱われる。
