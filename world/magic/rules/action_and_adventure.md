# 判定・クリティカル・勝負・成長・行軍力学 (Action, Resolution & Adventure Mechanics)

本ドキュメントは、現代（2026年）における魔獣戦闘、潜入、野外行軍、各種行動の成功判定基準、致命的クリティカル/ファンブル表、能力勝負・抵抗力学、および術士・ハンターの成長・訓練システムを定めた公式判定基準書です。

---

## 1. 成功判定と状況修正 (Success Rolls & Modifiers)

すべての行動（技能判定・能力値判定）は **3d6（6面ダイス3個の合計値）** が「実効目標値以下」であれば成功となる。

### 1.1 行為の難易度修正表 (Task Difficulty)
| 難易度区分 | 修正値 | 判定の具体例（現代魔獣戦・日常） |
| :--- | :---: | :--- |
| **自動的 (Automatic)** | なし (判定不要) | 障害物のない平地の歩行、日常的な電子レンジ調理。 |
| **極めて容易 (Very Easy)** | **+4 〜 +5** | 明るい射撃場での静止ターゲット射撃、平易な日用品の操作。 |
| **容易 (Easy)** | **+2 〜 +3** | 整備された結界都市内道路での運転、一般的な魔獣足跡の識別。 |
| **普通 (Favorable)** | **+1** | 多少の悪天候下での野外キャンプ設営。 |
| **標準 (Standard)** | **0** | **実戦における標準的な攻撃・回避・呪文詠唱・応急手当**。 |
| **困難 (Hard)** | **-1 〜 -2** | 降雨・夜間の射撃、警戒心の強い魔獣への忍び寄り。 |
| **非常に困難 (Very Hard)** | **-3 〜 -5** | 揺れるヘリからの狙撃、猛毒魔獣の戦闘中急速解体、マナ嵐下の詠唱。 |
| **絶望的 (Severe/Impossible)** | **-6 〜 -10** | 暗黒・暴風雨の中での精密射撃、未知のアビス変異種の即興毒素中和。 |

### 1.2 時間の消費と修正 (Time Spent)
- **急ぎ作業 (Haste)**: 所要時間を半分にするごとに **-1〜-2 のペナルティ**（最短で通常の1/10時間、最大-10）。
- **慎重作業 (Extra Time)**: 所要時間を2倍にするごとに **+1 ボーナス**（最大で30倍時間、+5ボーナス）。

## 2. クリティカルとファンブル (Critical Success & Failure)

### 2.1 発生条件
- **クリティカル成功**: ダイス目 **3 または 4**（目標値が15以上なら出目 **5**、目標値16以上なら出目 **6** も含む）。また「目標値より10以上低い出目」。
- **ファンブル（大失敗）**: ダイス目 **18**（目標値が15以下なら出目 **17** も含む）。また「目標値より10以上高い出目」。

### 2.2 クリティカル命中表 (Critical Hit Table)
戦闘時の攻撃判定でクリティカル成功を出した場合、相手は能動防御（よけ・受け・止め）を行えず、さらに以下の出目効果を適用する：

| 3d6出目 | 発生効果 |
| :---: | :--- |
| **3** | **致命的急所直撃**: ダメージ計算で **最大ダメージの3倍** を与える（相手の装甲DRは通常通り適用）。 |
| **4** | **装甲完全無視**: 相手の装甲（DR）を **完全ゼロ（DR 0）** としてダメージを計算。 |
| **5** | **最大装甲貫通**: 相手の装甲DRを半分にし、ダメージダイスは **すべて最大値** として計算。 |
| **6** | **大打撃**: ダメージ計算で **最大ダメージの2倍** を与える。 |
| **7 〜 8** | **脆弱部直撃**: 相手の装甲（DR）を半分として計算。 |
| **9 〜 11** | **通常直撃**: 通常通りのダメージを与える（能動防御不可）。 |
| **12 〜 13** | **激痛ショック**: 通常ダメージに加え、相手は直ちに **大ショック（次ターン全行動-4）** を受ける。 |
| **14** | **武器・体勢破壊**: 通常ダメージに加え、相手の構えている武器を弾き飛ばすか体勢を崩す（転倒判定）。 |
| **15** | **部位機能喪失**: 命中部位（腕・脚・翼など）が即座に **「不随（Crippled）」** となる。 |
| **16 〜 17** | **気絶ショック**: 通常ダメージに加え、相手は直ちに **生命力（HT）判定に失敗するとノックアウト（気絶）**。 |
| **18** | **即死級急所破壊**: 相手は直ちに **HT-3 判定**。失敗すれば即死、成功しても致命傷と気絶。 |

### 2.3 戦闘ファンブル表 (Critical Miss Table)
攻撃や能動防御でファンブルを出した場合、直ちに以下のトラブルが発生する：

| 3d6出目 | 発生効果 |
| :---: | :--- |
| **3 〜 4** | **最悪の誤射・誤撃**: 射線上の最も近い味方、または自身の足元に直撃（通常ダメージ）。 |
| **5 〜 6** | **自身への自爆・自傷**: 自身の武器・魔法が跳ね返り、自分自身に半分ダメージを与える。 |
| **7** | **武器破損・暴発**: 武器が完全に破壊される（銃器は暴発、刀剣は折損）。 |
| **8** | **武器の脱落・遠投**: 武器が手から滑り落ち、1d6m前方に転がる。 |
| **9 〜 11** | **手元狂い・武器落下**: 武器を足元に落とす。拾い上げるまで無防備。 |
| **12 〜 13** | **体勢崩壊・転倒**: 足をもつれさせて地面に転倒（伏せ状態）。次ターン立ち上がるまで行動制限。 |
| **14** | **筋肉挫傷・筋違え**: 腕や脚の筋を痛め、1d6分間該当部位の判定に -2 のペナルティ。 |
| **15** | **方向感覚喪失**: 眩暈・視界遮断により、次ターンの能動防御が一切行えない。 |
| **16 〜 17** | **一時的ショック**: 自身の動作の反動で 1 FP を喪失し、1ターンの間スタン（身動き不能）。 |
| **18** | **致命的自滅**: 転倒して頭部を強打、または武器が自身に直撃し **HT判定失敗で昏睡**。 |

## 3. 能力勝負と抵抗力学 (Contests & Resistance)

### 3.1 即決勝負 (Quick Contest)
- **判定方法**: 双方が同時に判定を行い、**「成功度の高い側（または失敗度の低い側）」** が勝利する。
- **勝利度**: （勝者の成功度）−（敗者の成功度）。勝利度に応じて効果の大きさ（吹き飛ばし距離、催眠深度等）が決定。
- **適用例**: 組みつきの振りほどき、早撃ち勝負、フェイント攻撃、ステルス vs 知覚。

### 3.2 通常勝負 (Regular Contest)
- **判定方法**: 双方が毎ターン判定を行い、**「一方が成功し、もう一方が失敗した瞬間」** に決着がつく。
- **適用例**: 腕相撲、長時間の持久力比べ、精神支配への持続的抵抗。

### 3.3 抵抗判定と「抵抗16のルール (Rule of 16)」
- 呪文や精神攻撃に対する目標の抵抗判定において、術士の実効技能レベルが **16以上** であっても、**抵抗判定の計算上は術士側の数値を「最大16（または対象のHT/意志力のいずれか高い方）」として扱う**。
- **目的**: 熟練術士の魔法であっても、被害者側に最低限（出目3〜4など）の抵抗成功の機会を保証する魔導物理原則。

## 4. キャラクター成長と訓練力学 (Advancement & Training)

### 4.1 CP（キャラクターポイント）の消費
魔獣討伐、任務達成、調査報告の提出によって獲得した経験点（CP）は、以下のレートで成長に割り当てられる：
- **能力値の上昇**: ST/HTは 10CP/点、DX/IQは 20CP/点。
- **副能力値の上昇**: HPは 2CP/点、FPは 3CP/点、意志力/知覚は 5CP/点。
- **技能レベルの向上**: 技能CP表に従い、1〜4CPずつ投入。

### 4.2 訓練時間と独学 (Study & Training Hours)
- **教官・指導者あり（専任研修）**: **200時間の訓練 = 1 CP**。
- **独学・自習（Field Study）**: **400時間の自主学習・実践 = 1 CP**。
- **メガコーポ魔導研修プログラム**: メガコーポ特待生・自衛隊特殊部隊は1日8時間・週5日（月160時間）の集中プログラムにより、約1〜2ヶ月で新規専門技能（〈銃火器〉〈魔法学〉等）を1レベル習得。

## 5. 肉体行動・野外行軍力学 (Physical Feats & Hiking)

### 5.1 登攀（Climbing）と掘削（Digging）
- **登攀判定**: 〈登攀〉技能判定。安全ロープなしでの失敗は直ちに「落下ダメージ（高さに応じた速度ダメージ）」を招く。
- **掘削能力**: 道具を持った平均的人間（ST 10）は、**1時間あたり約 0.3立方メートル（スコップ使用時 0.6立方メートル）** の土砂を掘削可能。

### 5.2 長距離行軍と疲労算出 (Hiking & Daily Travel)
- **平坦な道路（舗装路）での基本移動距離**:

$$\text{1日の行軍距離 (km)} = \text{基本移動力 (BM)} \times 16 \text{ (徒歩8時間)}$$

- **地形修正**:
  - **市街地・平坦路**: ×1.0
  - **未舗装路・森林**: ×0.75
  - **泥濘・山岳・奥多摩魔境**: ×0.5
  - **アビス特異点・急峻な岩山**: ×0.2
- **行軍疲労**: 1日の通常行軍（8時間）につき **1 FP を消費**。荷物の荷重レベル（軽荷・重荷等）や悪天候・高熱下では追加で 1〜3 FP を失う。
