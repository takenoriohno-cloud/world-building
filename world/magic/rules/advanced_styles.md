# 高度魔導流派・砲兵術式と儀式パス魔術 (Advanced Styles, Artillery & RPM)

本ドキュメントは、ガープス第4版サプリメント群（『Thaumatology』『Artillery Spells』『Death Spells』『The Least of Spells』『Ritual Path Magic』および `magic_page_279`〜`300`）を基に、専門魔導流派、軍事砲兵呪文、生活簡単呪文、儀式パス魔術（RPM）、および2026年現代軍事・スラム生活における実態を体系化した公式設定資料です。

---

## 1. 軍事砲兵系呪文 (Artillery Spells)

数百メートル〜数キロメートルの超長射程から、敵の拠点や巨大魔獣の群れを砲撃・破砕する大規模戦闘魔術。

| 呪文名 | 射程・範囲 | ダメージ・威力 | 消費FP | 現代軍事・自衛隊における比較 |
| :--- | :--- | :--- | :---: | :--- |
| **《長距離火球砲》**<br>Artillery Fireball | 最大2,000m / 半径5m | 6d〜12d 爆発 | 12〜24 | 81mm〜120mm迫撃砲弾に匹敵。 |
| **《重力圧壊砲》**<br>Gravitic Crush | 最大1,000m / 単体 | 10d 衝撃＋圧壊 | 18 | 105mm戦車砲HEAT弾に匹敵。 |
| **《連鎖落雷嵐》**<br>Chain Lightning Storm | 最大1,500m / 半径20m | 6d 電撃（装甲無視） | 25 | 155mm榴弾砲の面制圧＋電子妨害。 |

- **現代軍隊における運用**: 自衛隊特科部隊やメガコーポ重装PMCでは、術士単独ではなく「儀礼魔術分隊（主術士＋補給術士3名＋車載パワーストーン）」を編成し、155mm榴弾砲部隊と連携して障壁持ち大型魔獣を遠距離撃滅します。

## 2. 致死・禁忌系呪文 (Death & Forbidden Spells)

肉体ではなく「魂魄・生命中枢・アストラル体」を直接切断・消滅させる非人道術式。
- **《即死の指（Finger of Death）》**: 生命力（HT）対抗判定に失敗した対象を即座に心肺停止・即死させる。
- **《魂魄捕縛（Soul Jar）》**: 死亡直後の対象の魂を宝石・記憶媒体に永久封じ込める。
- **国際条約によるClass-C指定**: これらの呪文はジュネーブ条約および国際魔導協定（2018年）により**完全禁止（Class-C禁忌魔術）**に指定されており、行使した術士は国家反逆・戦争犯罪人として即時射殺対象となります。

## 3. 生活・簡単呪文 (The Least of Spells / Cantrips)

消費エネルギーが「1 FP未満」または極小の、一般市民やスラム住民が日常で多用する便利小魔術。

| 呪文名 | 効果概要 | 現代都市・スラムでの実態 |
| :--- | :--- | :--- |
| **《着火（Sparks）》** | 指先から小さな火花を出す。 | マッチ・ライター不要のタバコ着火、コンロ点火。 |
| **《水滴清掃（Dry Clean）》** | 衣服の泥・水滴・油汚れを弾き落とす。 | スラム街の過酷な衛生環境での病気予防。 |
| **《微風扇風（Cool Breeze）》** | 顔周りに涼しい微風を吹かせる。 | 夏場のエアコンのない特別居留区での熱中症対策。 |
| **《鮮度微保（Keep Fresh）》** | 弁当や食材の腐敗を数時間遅らせる。 | Class-A魔獣肉の野外保存。 |
| **《静音囁き（Quiet Whisper）》** | 数m離れた味方にだけ聞こえる小声を送る。 | 密輸ハンターや不良グループの合図。 |

## 4. 儀式パス魔術 (Ritual Path Magic / RPM)

無数の個別呪文を覚えず、9大パス（時間・空間・精神・物質・エネルギー・生体・偶然・魔力・アンデッド）からマナを儀式的に集積（Gather Energy）してあらゆる奇跡を創造するフレキシブル魔術体系。
- **エネルギー集積**: 術士は瞑想・詠唱・触媒使用を繰り返し、必要な魔力値（数点〜数百点）が溜まるまでターン・時間ごとに判定を重ねる。
- **バックラッシュ**: 集積判定でファンブルすると、溜まった莫大なマナが術士の肉体に逆流して致命的な変異・爆発を引き起こす。
- **現代オカルト結社**: 組織化されたメイジではなく、裏社会の呪術師や独立系フリーランスハンターが多用する。
