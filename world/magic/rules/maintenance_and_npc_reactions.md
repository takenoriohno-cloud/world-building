# 装備メンテナンス・故障・NPC反応力学 (Maintenance, Malfunctions, Broken Weapons & NPC Reactions)

本ドキュメントは、現代（2026年）における銃火器・車両・魔導装備の日常メンテナンス・故障値（Malf.）、壊れた武器の修復、およびNPC反応判定表（3d6）・社会的偏見修正力学を定めた公式基準書です。

---

## 1. 装備メンテナンスと銃器故障力学 (Maintenance & Malfunctions)

過酷な壁外魔境（泥濘、火山灰、アビス粘液）における機材の損耗と故障。

### 1.1 メンテナンス間隔と怠慢ペナルティ
- **通常火器・車両**: 週に 1回の定期分解清掃（〈銃火器〉または〈機械修理〉判定）。
- **メンテナンス怠慢**: 1週間怠るごとに、武器の故障値（Malf.）が **1点悪化**（例: 16 $\rightarrow$ 15 $\rightarrow$ 14）。
- **アビス汚染域での即時損耗**: 酸性雨や腐食性胞子に晒された場合、1回の交戦ごとに清掃が必要。

### 1.2 故障（ジャム）の野戦クリアランス (Immediate Action / Clears)
- **判定**: 〈銃火器/TL8〉判定（1秒の準備マニューバ）。
- **成功**: 薬莢排出・次弾装填完了。次ターン射撃可能。
- **失敗**: 激しい薬室噛み込み（工具を用いた 3d 秒の分解作業が必要）。

## 2. 壊れた武器と修復 (Broken Weapons & Restoration)

### 2.1 武器の破損状態
- **刃こぼれ / 銃身歪み**: 致傷力 -1、命中判定（Acc）-1。
- **柄折れ / 機関部破壊**: 使用不能。折れた日本刀・銃剣は「ダガー（刺突 1d-1 imp）」としてのみ使用可能。

### 2.2 大修理力学（呪文《大修理》 / Rebuild Spell）
- **通常修理**: 鍛冶工・銃砲工による数日〜数週間の作業。
- **《大修理》（Rebuild）**: 破片が 80% 以上揃っていれば、魔力消費（15 FP）により数分で原型通りに分子結合復元。

## 3. NPC反応判定と社会的偏見力学 (NPC Reactions & Social Modifiers)

見知らぬNPC（警察官、居酒屋店主、闇商人、メガコーポ幹部）とのファーストコンタクト。

### 3.1 NPC反応判定表 (Reaction Table / 3d6)
| 3d6合計値 | 反応結果 | NPCの態度と行動 |
| :--- | :--- | :--- |
| **3 以下** | **最悪 (Disastrous)** | 即座に敵対。通報、攻撃、罠にかける、一切の交渉拒絶。 |
| **4 〜 6** | **悪い (Poor)** | 露骨な嫌悪・不快感。高圧的態度、割高な価格提示（2倍）。 |
| **7 〜 9** | **普通・冷淡 (Neutral)** | 事務的・無関心。標準的な商取引のみ（手助けはしない）。 |
| **10 〜 12** | **好意的 (Good)** | 親切で協力的。標準価格、簡単な情報提供。 |
| **13 〜 15** | **非常に良い (Very Good)** | 熱心な協力。値引き（10〜20%）、貴重な裏情報の提供。 |
| **16 〜 18** | **最良 (Excellent)** | 無条件の信頼・忠誠。命がけの支援、最高機密の開示。 |

### 3.2 現代日本における反応修正 (Modifiers)
- **新人類（エルフ/ドワーフ/トロール）への社会的偏見**: -1 〜 -3（一般市民街・警察官）。
- **魔力適性者ID不携帯**: -4（治安部隊の警戒度最大化）。
- **高ステータス (Status 2+) / メガコーポ社員バッジ**: +1 〜 +3（一般市民・店主）。
- **名声 (Reputation: 凄腕ハンター / 結界防衛の英雄)**: +1 〜 +4。
- **魅力・カリスマ (Charisma / Beautiful)**: +1 〜 +4。
