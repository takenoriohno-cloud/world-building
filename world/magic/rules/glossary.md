## 1. 現代魔術の基本専門用語

| 用語 | 英語表記 | 定義・現代世界観における解釈 |
| :--- | :--- | :--- |
| **マナ (Mana)** | Mana | 2000年に覚醒した霊的エネルギー。非物質性であり、生体・魂・神経系にのみ作用する。 |
| **魔法の素質** | Magery | 生体組織内にマナを蓄積・制御できる生体形質（メタヒューマンや高適性人種に顕著）。 |
| **呪文 (Spell)** | Spell | アストラル体および神経電位を介して特定の物理・生体現象を励起する定型化された術式プログラム。 |
| **術者 (Caster)** | Caster | 呪文を励起・制御する術士（メイジ、巫女、陰陽師、PMC術士等）。 |
| **被術者 / 目標** | Subject / Target | 呪文の作用対象となる生物、霊体、または特定の物体・機械。 |
| **疲労点 (FP)** | Fatigue Points | 呪文行使に伴い消費される生体エネルギー。限界を超えると生命力（HP）を削る。 |
| **文明レベル (TL)** | Tech Level | 技術・科学の発展段階（現代はTL8、最先端電脳魔術はTL9相当）。 |
