# 現代特務キャリア・ムーク戦闘力学・組織運用ルール (Tactical Careers, Mook Combat & Organization Rules)

本ドキュメントは、「現代魔獣・幻獣生態図鑑」における**現代特務・専門職系譜テンプレート群（Career Archetypes）**、**大群・雑魚（ムーク / Mook）戦闘高速処理力学**、**足手まとい（Dependents）護衛力学**、および**メガコーポ・ギルド組織運用テンプレート**を定めた正史ルールアーカイブである。

---

## 2. 大群・雑魚（ムーク / Mook）戦闘高速処理力学

大量の小型魔獣（ゴブリン、低級ゾンビ、変異ラット、スライム群等）と遭遇した際、戦闘処理を高速化するための公式ルール。

```
┌─────────────────────────────────────────────────────────────┐
│                 ムーク（Mook）高速処理の4大原則              │
├─────────────────────────────────────────────────────────────┤
│ ① 有効打撃即座脱落 ── メジャーダメージ（HP半分以上）で即無力化 │
│ ② 能動防御の固定化 ── よけ/受け判定を省略（固定値 Dodge 8等）│
│ ③ 集団攻撃・集団射撃 ── 3〜5体を1グループとして一括ダイス判定 │
│ ④ 士気崩壊連鎖     ── 隊長死亡または半数撃破で即座に敗走   │
└─────────────────────────────────────────────────────────────┘
```

1. **即座無力化（One-Hit Takedown）**:
   - ムークはHP管理を省略し、**1回の攻撃で「HPの半分以上」のダメージを受けるか、防護点を貫通するクリティカルヒットを受けた時点で即座に戦闘不能（死亡または行動不能）**となる。
2. **能動防御の簡略化**:
   - 個別の能動防御（よけ・受け・止め）は振らず、PCの攻撃成功度が「ムークの固定回避値（通常 8〜9）」を上回っていれば自動命中とする。
3. **集団攻撃（Mob Attack）**:
   - 3〜5体のムークが1人のPCに同時攻撃する場合、代表で1回だけダイスを振り、**攻撃力に「グループ人数-1」のボーナス**（例: 4体なら命中+3、ダメージ+3）を適用する。
4. **士気判定（Morale Check）**:
   - 部隊のリーダーが倒されるか、総数の50%が倒されたターン終了時に【3d6 <= 10】の士気判定を行う。失敗すると残存個体は全速力で逃走（Flee）する。

## 3. 足手まとい（Dependents / Deadweight）の現場護衛力学

重要NPC（依頼主のメガコーポ役員、同行する民間研究員、救出対象の市民等）を壁外や戦闘区域で護衛する際のルール。

- **パニック判定（Panic Check）**:
  - 魔獣の咆哮や銃撃戦が発生した際、護衛対象は毎ターン【IQ または 意志力 3d6 <= 10】の判定を行う。
  - **失敗時の行動**:
    - `1〜2点差で失敗`: **立ちすくみ（Freeze）** ── その場にしゃがみ込み行動不能（回避-4）。
    - `3〜4点差で失敗`: **無秩序逃走（Panic Run）** ── 危険な方向（魔獣の群れ側やトラップ方向）へ無我夢中で疾走。
    - `5点以上またはファンブル`: **絶叫・発狂（Hysteria）** ── 大声で叫び続け、周囲300m以内の魔獣の索敵判定に+5のボーナスを与える。
- **PCの沈静化行動**:
  - 【統率（Leadership）】または【心理学】技能判定（1ターン消費）に成功することで、護衛対象のパニックを解除し指示に従わせることができる。

## 4. メガコーポ・ギルド組織運用テンプレート

プレイヤーやNPCが所属する組織（特務部隊、PMC小隊、ハンターギルド分隊、カルト結社）の規模とバックアップ能力を定義するルール。

```
【組織スペックの評価項目】
・規模 (Scale)       ── 分隊 (4〜10名) / 小隊 (30〜50名) / 大隊 (300名以上)
・資源力 (Resources) ── TL8標準装備 / 魔導特化兵器 / 装甲車両・航空支援
・士気 (Morale)     ── 10（一般雇用） / 12（精鋭PMC） / 14（狂信カルト）
・忠誠度 (Loyalty)   ── 賃金依存（-2ペナルティ） / 思想・血縁共有（+3ボーナス）
```

- **組織からの支援要請**:
  - 【事務管理】または【人脈（メガコーポ）】判定に成功することで、**重火器弾薬補給**、**救難ヘリ・装甲車による緊急回収**、**結界都市ゲートの優先通過権**を獲得できる。

## 5. 個性化・癖（Quirks）リスト

キャラクターやNPCに独自のリアリティと個性を付与する軽微な特徴（各 -1 CP、最大5個まで取得可能）：

1. **魔導煙草愛好**: 精神集中のために低濃度マナ葉の煙草を常に吸っている。
2. **壁外潔癖症**: 魔獣の体液が付着すると即座に除染スプレーを使わずにはいられない。
3. **特定メガコーポ嫌い**: 特定の製薬会社や軍事企業製品を頑度に使用拒否する。
4. **月輪拝礼**: 毎晩、月が出ると特定の月輪神性に向かって無言で30秒祈りを捧げる。
5. **ジビエ美食家**: 討伐した魔獣がClass-AまたはClass-Bの場合、必ず一部を試食しようとする。
