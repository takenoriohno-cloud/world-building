# 新人類亜種・アビス変異種族・異界生物群 (Subhuman Meta-Races, Abyss Inhabitants & Mutated Fauna)

本ドキュメントは、「現代魔獣・幻獣生態図鑑」における**新人類（メタヒューマン）亜種テンプレート**、**アビス特異点由来の深淵異形種（Abyss Entities）**、および**変異使役動物・野生生物群**の生態・戦闘データ・解体資源基準を定めた正史ルールアーカイブである。

---

## 1. 新人類（メタヒューマン）亜種・種族テンプレート群

2000年のミレニアム・アウェイクニングによる急速マナ変異、および異界断層の接触によって定着した新人類の亜種テンプレート。社会的には特別居留区（東京湾岸スラム等）やメガコーポの契約労働、壁外PMCなどに従事している。

```
                       【新人類（メタヒューマン）の4大系統】
                                       
             [霊的・長命系 (エルファ / ゲルーシャ / ダークエルフ)]
                                       │
     [強靭・工学系 (ドワーフ / ドヴェルグ)] ── [獣人・俊敏系 (ミュルーン / ギャビット / フェリア)]
                                       │
             [異形・重装甲系 (ディワン / ウーティ / 翼人 / 爬虫人)]
```

## 2. アビス深淵異形種・生態力学データ

アビス特異点やマナ汚染濃度AAA級の魔境から流入する、地球外・異次元生態系の脅威生物群。

```
┌─────────────────────────────────────────────────────────────┐
│                 アビス深淵異形種の3大脅威特性                │
├─────────────────────────────────────────────────────────────┤
│ ① 〈多足のもの〉   ── 垂直壁面強襲・全方位複数打撃・粘着糸拘束 │
│ ② 〈姿なきグルグドゥ〉── 完全光学的・魔導不可視・精神波捕食 │
│ ③ 重装甲異界魔獣群 ── 超硬度外骨格・腐食性強酸分泌・突進破砕 │
└─────────────────────────────────────────────────────────────┘
```

### 2.1 危険生物エントリー

#### ① 〈多足のもの〉 (Multi-Legged Stalker) ── Threat Level III
- **形態**: 直径3m、12本の節足を持つ漆黒のクモ・ムカデ複合型異界生物。
- **能力値**: ST 18, DX 14, IQ 6, HT 12 / HP 22, Move 9 (壁面移動 8)
- **特殊能力**:
  - **3次元機動**: 天井・垂直壁面を減速なしで移動。
  - **連続攻撃（3回攻撃）**: 鋭利な節足による刺突（2d6+2 cut / 装甲除数(2)）。
  - **粘着糸噴射**: 射程10m、命中すると相手を拘束（ST 20 対抗判定）。
- **軍事対処**: 5.56mm小銃では外殻で弾かれる恐れあり。**12.7mm重機関銃**または**火炎放射器**での焼却が推奨される。
- **資源分類**: **Class-C（汚染種）**。肉は劇物。外殻節足は高強度複合素材として建材・防刃ベストに利用（1体あたり約30万円）。

#### ② 〈姿なきグルグドゥ〉 (Unseen Gurgdu) ── Threat Level IV
- **形態**: 物理的実体を持つが、可視光・赤外線・標準魔導感知を透過する完全不可視の捕食者。
- **能力値**: ST 16, DX 13, IQ 9, HT 14 / HP 20, Move 7
- **特殊能力**:
  - **完全不可視（Chameleon/Invisibility）**: 視覚による発見判定に -10 ペナルティ。音（聴覚判定 -3）または熱感知（生体熱遮断時はマナ揺らぎ感知 -4）のみで追跡可能。
  - **精神波捕食（Psychic Drain）**: 接触した対象の精神エネルギーを直接吸引（毎秒 1d6 FP＋正気度判定/恐怖判定 -4）。
- **軍事対処**: 目視照準不可のため、**広範囲散弾（ショットガン）**、**煙幕・蛍光塗料散布**による輪郭可視化、または**専門術士の精神探知**が必須。
- **資源分類**: **Class-C（汚染種）**。死骸は急速に昇華して消滅するが、心核（アビス・コア）は高純度マナバッテリーとしてメガコーポが1個200万円で買い取る。

#### ③ ケラーグ / オレアノイ / ゴレイキ (Abyss Heavy Brutes) ── Threat Level III〜IV
- **形態**: 全長4〜6m、分厚いキチン質甲殻と三叉の角、強酸噴射器官を持つ重装甲魔獣群。
- **戦闘データ**: ST 30〜45, HP 40〜60, DR 15〜25（徹甲弾以外を無効化）。
- **特殊攻撃**:
  - **猛突進（Slam）**: 4d6+4 叩きダメージ＋衝撃波転倒。
  - **腐食酸噴射**: 射程15m、3d6 腐食ダメージ（命中部位のDRを毎ターン2点永続減少）。
- **軍事対処**: 通常歩兵小銃は完全無効。**対戦車誘導弾（ATM）**、**30mm機関砲**、または**重火器集中射撃**で装甲を破砕して撃破する。
- **資源分類**: **Class-B（要処理種）**。甲殻は戦車用反応装甲素材、角は魔導触媒。肉は酸中和処理を施せば一部食用可能。

## 3. 変異使役動物・野生生物群

マナ適応によって知能や体質が変異した動物群。ハンターの使役獣（相棒）や警備犬として広く利用されている。

```
【変異使役動物のスペック】
・品種改良魔獣猟犬 (Bred Hounds) ── 嗅覚+5、咬合力ST 14、魔気探知（マナ追跡技能 14）
・牙ムササビ (Saber Glider)     ── 樹上・屋上索敵、滑空奇襲（1d6+1 cut）、暗視
・二本鼻 (Twin-Trunk Ferret)    ── 狭所潜入・配線切断・毒物検知（嗅覚+4）
・猫モドキ (Pseudo-Feline)      ── 霊体感知（ゴースト視認）、睡眠誘導鳴き声（HT判定）
```

- **使役・訓練**: 動物調教技能（Animal Handling/TL8）およびマナ親和判定により、術士・ハンターの命令を忠実に実行する。
- **資源分類**: **Class-A（安全種）〜 Class-B（要処理種）**。適切に解体・調理された猟犬・小動物系ジビエは栄養価が高く壁外キャンプの貴重なタンパク源となる。
