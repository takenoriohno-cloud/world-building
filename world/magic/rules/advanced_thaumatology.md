# 上級魔導理論・注入技能・閾値力学 (Advanced Thaumatology & Imbuements)

本ドキュメントは、現代（2026年）における魔導行使の発展的体系、生体媒介による武器・弾丸へのマナ注入技術（Imbuements）、マナ特異点や過剰詠唱下における閾値魔法力学（Threshold-Limited Magic）、および精霊・精神体・呪詛儀式を規定した公的魔導物理・実戦基準書です。

---

## 1. 注入技能と生体媒介エンチャント（Imbuement Skills）

### 1.1 注入能力の基本構造
現代では恒久的な魔法付与（エンチャント）兵器の工業的量産が未確立であるため、術士自身が生体電位とマナを同調させ、**手にした武器や装填された弾薬に一時的な魔導属性を付加する「注入技能（Imbuement Skills）」**が実戦（対魔獣戦・対霊体戦）における主力を担う。

- **前提有利特徴**: **「注入力（Imbue）」**（レベル1〜3）
  - **レベル1**: 近接白兵武器への注入のみ可能。
  - **レベル2**: 投擲武器・人力射撃武器（弓・クロスボウ）への注入が可能。
  - **レベル3**: 近代銃火器の弾薬（5.56mm/7.62mm/12.7mm弾等）への注入が可能。
- **行使コスト**: 注入1回につき **FP 1（または対応するエネルギー）** を消費。攻撃判定と同時に〈注入技能〉判定を行う。

### 1.2 実戦注入技能一覧（主要分類）
| 注入技能名（原語） | 難易度 | 属性・効果概要 | 現代実戦での運用・対魔獣戦術 |
| :--- | :--- | :--- | :--- |
| **〈衝撃付与〉 (Forceful Blow)** | 敏捷/至難 | 叩き属性付与、ノックバック距離を2倍に強化。 | 装甲の硬い大型甲殻魔獣の体勢崩し・突進阻止。 |

| **〈炎上付与〉 (Incendiary Weapon)** | 敏捷/至難 | 攻撃に「火炎・焼夷（inc）」属性を付加し、発火判定。 | 再生能力を持つ植物系魔獣・変異スライムの細胞焼却。 |

## 2. マナ制御・資質と対抗力学

### 2.1 魔法の素質（Magery）と特殊変異
- **魔法の素質（Magery 0〜4+）**: 生体内のマナ受容神経の密度を示す。
  - **Magery 0 [5cp]**: マナ感知が可能、マナ高濃度域での基礎魔法行使資格。
  - **Magery 1〜3 [10cp/Lv]**: 呪文の習得上限解放、知力・技能判定への直接ボーナス。
  - **単科学派限定（One-College Only）[-40%]**: 火炎系のみ、治癒系のみ等。
  - **生体媒介限定（Biological Only）[-20%]**: 電子端末や機材を経由せず、自身の生体接触でのみ発動。

### 2.2 真の信仰とマナ干渉（True Faith / Mana Enhancer & Damper）
- **真の信仰（True Faith）[15cp]**:
  - 神道・修験道・伝統宗教の祈祷師が持つ聖性。精神体・アンデッド・深淵系変異体は術士の半径数メートル内に意志判定なしで接近できない。
  - **追加増強「害敵退散（Turning）」(+65%)**: 接近を拒むだけでなく、対象に恐怖判定・ダメージを与える。
- **マナ増幅（Mana Enhancer）[50cp/Lv]**:
  - 術士の周囲（半径数m）のマナ濃度を1段階上昇させる（低マナ→通常マナ、通常マナ→高マナ）。
- **マナ除去（Mana Damper）[50cp/Lv]**:
  - 術士の周囲のマナ濃度を1段階低下させる（高マナ→通常マナ、通常マナ→低マナ、低マナ→無マナ）。敵性術士の詠唱を無力化する対魔作戦用特異体質。

## 3. 閾値魔法力学（Threshold-Limited Magic）

### 3.1 タリー（Tally）と閾値（Threshold）システム
アビス特異点周辺や高濃度マナ汚染地域（特異災害地域）では、通常の疲労点（FP）消費ではなく、**環境中に蓄積される魔力負荷「タリー（Tally）」**によって魔法が駆動する。

$$\text{許容閾値 (Threshold: Th)} = \text{基本値 (例: 30)} + (\text{Magery} \times 10)$$

- **タリーの蓄積**: 呪文を消費エネルギー 1 相当で行使するごとに、術士の「タリー値」が 1 上昇する。
- **回復レート（Recovery Rate: Rr）**: 1日（24時間）あたり 8 点ずつ自然減少。

### 3.2 厄災判定（Calamity Check）
タリーが許容閾値（Th）を超過した状態でさらに呪文を行使した場合、超過分に応じた**「厄災判定（3d6 + 超過修正）」**が発生する。

| 厄災ダイス出目 | 厄災レベル | 発生現象・生体および空間への反動 |
| :---: | :---: | :--- |
| **3 〜 10** | **軽微 (Minor)** | 一時的な眩暈、鼻血、肌の軽微な発光（1d6分間）。 |
| **11 〜 15** | **中度 (Moderate)** | FPの一時的枯渇（残FPが1になる）、生体電位の乱れ（電子機器操作に-3ペナルティ）。 |
| **16 〜 20** | **重度 (Major)** | **局所的マナ嵐**: 半径5m以内の電子機器がショート、術士は 2d6 の電撃・衝撃ダメージ。 |
| **21 〜 25** | **深刻 (Severe)** | **生体マナ変異**: 体の一部が異形化（角の発生、皮膚の硬化等）、精神的狂気判定（自制値12）。 |
| **26以上** | **破滅 (Cataclysmic)** | **アビス特異点小規模開孔**: 術士のアストラル体が焼き切れる（即死または昏睡）、周囲に異界魔獣が召喚。 |

## 4. 精霊・ゴーレム・支援霊体系

### 4.1 四大源素精霊の共通性質（Elemental Meta-Traits）
| 精霊種別 | 構成源素 | コア特性・防御力 | 物理攻撃に対する挙動 |
| :--- | :--- | :--- | :--- |
| **地精 (Earth Elemental)** | 岩石・土砂 | DR 6〜12、叩き・斬撃耐性、高重量・鈍足。 | 通常火器で粉砕可能（徹甲弾が極めて有効）。 |
| **風精 (Air Elemental)** | 大気・突風 | 実体なし（DR 0）、打撃・貫通無効、気体透過。 | 爆風（榴弾）や魔導障壁・真空化で霧散。 |
| **火精 (Fire Elemental)** | 高温プラズマ | 接触時熱ダメージ（2d6 炎）、可燃物発火。 | 消火剤・放水銃・冷却弾により急激に弱体化。 |
| **水精 (Water Elemental)** | 流体水塊 | 刺突・貫通ダメージ半減、水中完全移動。 | 水流破壊（指向性爆破）や凍結呪文で無力化。 |

### 4.2 支援霊（Assisting Spirits）と非魔術師行使
- **支援霊の媒介**: 先住民族の精霊信仰や陰陽道において、術士自身の資質（Magery）が低くても、**契約した守護霊・式神（支援霊）がマナを肩代わりして呪文を発動する**。
- **リスク**: 支援霊の機嫌（好感度）を損ねると、指示を拒絶されたり反逆（憑依・精神汚染）を受ける危険が伴う。

## 5. 儀式・真名・呪詛力学

### 5.1 真名（True Names）の束縛力
- あらゆる魔獣・精霊・術士には魂の固有周波数を示す「真名」が存在する。
- **効果**: 対象の真名を知る術士は、その対象への呪文・精神干渉・精神抵抗判定において **+5の圧倒的ボーナス** を得る。
- **防護策**: 名を偽る（偽名・コードネームの徹底）、魂の周波数を遮断する呪符の携行。

### 5.2 生贄ボーナス（Sacrifice Bonuses）と深淵呪術
- 儀式魔術において、生きた生体組織・血液を捧げることで詠唱エネルギーを補填する禁忌力学。
  - **小型動物（鶏・兎等）**: +1〜+2 エネルギーボーナス。
  - **大型魔獣・人間**: +5〜+20 以上の強大なマナ供給。
- **憲章規制**: 人間を生贄とする行為は国際特異災害対策機構（ISDA）および国内法により**最高ランクの死刑相当罪名（深淵外法行使罪）**に指定。

### 5.3 死の呪い（Death Curses）
- 強力な術士や高知能魔獣が生命活動を停止する瞬間、自身の魂と最後の全マナを燃焼させて放つ不可避の呪詛。
- **発動条件**: 対象が死亡した瞬間に即時自動発動（抵抗判定は生命力 HT または意志力 Will）。
- **効果**: 致命的な病変、継続的ダメージ、または運命の歪曲（「不幸」特徴の恒久付与）。

## 6. 超能力（Psionics）と精神体の力学

### 6.1 超能力と魔術の差異（完全並行）
| 比較項目 | 魔術（Thaumatology） | 超能力（Psionics） |
| :--- | :--- | :--- |
| **エネルギー源** | 環境中のマナ（生体・空間の霊的場） | 術者本人の脳神経生体電位・精神波 |
| **マナ濃度依存性** | 濃度の影響を直接受ける（無マナで沈黙） | **マナ濃度に完全無依存**（無マナ地域でも発動可能） |
| **対抗・防御手段** | 魔導障壁、対抗呪文、除霊 | 精神障壁（Mind Shield）、生体電磁遮蔽 |
| **検出性** | マナ探知機、オーラ視認で検知可能 | 脳波計・サイオニック・スキャンでのみ検知 |

### 6.2 精神体（Spirit Meta-Trait）の共通性質
- **実体なし（Insubstantiality）**: 物理的壁面・銃弾を100%透過。通常兵器によるダメージを一切受けない。
- **不可視（Invisibility）**: 通常の可視光線・赤外線カメラに写らない（マナ探知スコープや術士のオーラ視でのみ視認可能）。
- **駆逐手段**: 〈除霊（Exorcism）〉技能、〈霊体打撃〉が付与された弾丸、神道・仏教の加持祈祷、純銀製呪具。
