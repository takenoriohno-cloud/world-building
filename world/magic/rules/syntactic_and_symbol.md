# 術語魔法・ルーン紋章と即席魔術力学 (Syntactic, Symbol & Improvised Magic)

本ドキュメントは、ガープス第4版『魔法大全』第27章「さまざまな魔法（Variations）」および関連データ（`magic_page_201`〜`226`）を基に、即席魔法（Improvisational Magic）、術語魔法（名詞動詞魔術 / Syntactic Magic）、紋章魔法（フサルク・ルーン / オガム文字 / Symbol Magic）、および2026年現代電脳魔術におけるプログラム言語的解釈を体系化した公式設定資料です。

---

## 1. 即席魔法力学 (Improvisational Magic)

固定の呪文リストを習得せず、術士の意志と状況に応じてその場で術式を動的構築する高位魔術。

### 1.1 万能の天才（Wild Talent）と万能魔法（Wildcard Magic）
- **万能の天才**: 術士が未習得の呪文を「あたかも知っていたかのように」一度だけ即座に行使する天賦の才。
- **万能魔法技能（Spells!）**: 単一の呪文ではなく、系統全体または魔術全般を包括するワイルドカード技能。膨大なキャラクターポイントを要するが、あらゆる通常呪文を前提条件なしで即興発動できる。

## 2. 術語魔法（名詞動詞魔術 / Syntactic Magic）

言葉の「動詞（Verbs）」と「名詞（Nouns）」を組み合わせて、あらゆる魔術現象を文法構造としてプログラミング・発現させる体系。

### 2.1 構文要素と組み合わせ

| 動詞技能（Verbs） | 名詞技能（Nouns） | 構文例と発現効果 |
| :--- | :--- | :--- |
| **《作成する（Create）》** | **《火（Fire）》** | `Create + Fire` ＝ 火炎を空間に生成。 |
| **《移動させる（Move）》** | **《土・岩（Earth）》** | `Move + Earth` ＝ 土砂を隆起・移動させて防壁形成。 |
| **《感知する（Sense）》** | **《精神（Mind）》** | `Sense + Mind` ＝ 周囲の敵性知性体をレーダー探知。 |
| **《変化させる（Transform）》** | **《肉体（Body）》** | `Transform + Body` ＝ 肉体を鋼鉄化・硬質化。 |
| **《制御する（Control）》** | **《機械（Machine）》** | `Control + Machine` ＝ 遠隔から電子ロック・車両をハッキング。 |
| **《強化する（Strengthen）》** | **《防護（Shield/Armor）》** | `Strengthen + Armor` ＝ 防弾プレートのDRを一時ブースト。 |

### 2.2 尺度（Scaling）とエネルギー計算
術語呪文の消費エネルギーは、対象の重量・体積・射程・持続時間に応じた「尺度パラメータ」によって動的に算出されます。
- **現代電脳魔術との親和性**: メガコーポ（レンラク、三ツ菱マナテック等）の研究者は、術語魔法の文法構造をコンピュータ言語（Python/Rust等）のAPIコールに対応させる「電脳魔導コンパイラ」を試作・実験しています。

## 3. 紋章魔法（ルーン・オガム魔術 / Symbol Magic）

物質の表面に特定の幾何学紋章（ルーン文字・オガム文字）を刻印・描画することで、遅延発動や恒久結界を構築する古代・伝統魔術。

### 3.1 二大紋章体系
1. **フサルク・ルーン（Elder Futhark）**:
   - ゲルマン・北欧起源の24文字のルーン。各文字が特定の概念（火・雹・太陽・巨人・防御・旅等）を象徴し、直接的な破壊・防御・天候操作に強みを持つ。
2. **オガム・アルファベット（Ogham Script）**:
   - ケルト起源の樹木文字（20文字）。樹木の精霊力・生体治癒・精神防護・土地結界に絶大な親和性を発揮。

### 3.2 緊急刻印とトラップ防衛
- **現場での急速刻印**: 術士がチョーク、塗料、ナイフ、または自身の血液を用いて壁や床にルーンを描くことで、数分〜数時間の時限爆弾や侵入感知トラップを設置可能。
- **結界要塞への恒久刻印**: 東京の多層同心円要塞線（国道16号・外環壁）のコンクリートブロック内部には、数千個のルーン紋章がプレキャスト成形時に埋め込まれており、物理的衝撃をマナ障壁に変換するハイブリッド装甲として機能しています。
