# 物体・建造物破壊・盾破損・修理修復力学 (Damage to Objects, Buildings, Shields & Repair Mechanics)

本ドキュメントは、現代（2026年）における防護壁、強化ドア、掩蔽壕、車両装甲、戦術盾の耐久力・破壊貫通力学、および工学修理・魔導修復呪文のルールを定めた公式基準書です。

---

## 1. 物体・遮蔽物・機械へのダメージ (Damage to Objects)

### 1.1 物体の材質と防護点 (DR)
| 材質 | 厚さあたりの防護点 (DR) | 典型的な構造物 |
| :--- | :--- | :--- |
| **強化木材 / 合板** | DR 1〜2 / cm | 一般家屋のドア、木製家具 |
| **強化ガラス / 防弾ガラス** | DR 3〜10 / cm | 車両窓、防護シールド |
| **コンクリート / 鉄筋** | DR 4〜6 / cm | 結界都市要塞壁、ビル外壁 |
| **軟鋼 / 鉄板** | DR 15〜20 / cm | 装甲車外板、防爆ドア |
| **チタン / 複合装甲プレート** | DR 30〜40 / cm | 戦術外骨格、特務装甲板 |
| **オリハルコン / 魔導強化鋼** | DR 60〜80 / cm | 結界基盤コア、特務専用刀剣 |

### 1.2 耐久力 (HP) と構造破壊
- **物体のHP算出**: 質量（重量）の立方根に材質係数を掛け合わせて算出。
- **機能停止**: HPの 50% を失うと機能不全・ジャム・亀裂。HP が 0 になると完全破損・破壊。

## 2. 盾へのダメージと盾破壊力学 (Damage to Shields)

戦闘中に攻撃を「盾止め（Block）」した場合の盾への負荷。

### 2.1 盾の耐久力基準
- **軽戦術盾 (Light Riot Shield / DB+1)**: DR 4, HP 20
- **重突入盾 (Heavy Ballistic Shield / DB+2)**: DR 12, HP 40
- **魔導強化大盾 (Tower Shield / DB+3)**: DR 20, HP 60

### 2.2 盾への直接ダメージ
- **過大ダメージ**: 攻撃の致傷力が盾の DR を超えた場合、余剰ダメージが盾の HP を削る。
- **盾の破損**: HP が 0 になると盾は砕け散り、以後盾止め不可。貫通したダメージは使用者の腕に到達する。

## 3. 修理・整備・魔導修復力学 (Repair & Thaumaturgical Restoration)

### 3.1 通常工学修理 (Engineering Repair / TL8)
- **修理判定**: 〈機械修理/TL8〉〈電子機器修理/TL8〉〈防具工〉技能判定。
- **必要時間**: 軽度損傷（数時間）、大破損（数日＋交換部品）。

### 3.2 魔導修復呪文体系 (Repair Spells)
- **《小修理》（Simple Repair）**: 重量 5kg までの非魔導物品の亀裂・破損を数秒で完全復元（消費 2 FP）。
- **《修理》（Repair）**: 巨大な機械・車両・魔導装備の構造的破壊を分子レベルで修復。
- **《魔導装備再生》（Reconstruct）**: 破損した魔化呪具のエンチャントを損なわずに修復する至難呪文。
